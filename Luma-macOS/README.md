> **拾，是拾起；光，是光影；拾光，也是时光。**
> 我们相信，每一张照片都是一束被留下的光。拾光，就是替你把散落的光，一片一片捡回来。

---

## 这是什么

拾光（Luma）是一款**完全本地运行**的 macOS 原生照片与媒体管理应用。

它把三件原本分裂的事放进同一个窗口：**打开你自己的图库**、**接入系统「照片」图库**、**直连网络存储与影视源**。不迁移、不上传、不需要账号——照片默认不必离开这台 Mac。

- **照片是自己的**：图库是一个标准 `.photoslibrary` 包，放在本机任意目录或外置磁盘；收藏、关键词、评分、查看时间等补充数据写在库内旁挂数据库，绝不改动 Apple 的 `Photos.sqlite` 一行。
- **界面是克制的**：对齐系统「照片」的浏览心智，年 / 月 / 所有照片、相簿、人物、场景、地点一屏可达；四种网格形式、键盘优先、深浅色与强调色即时联动。
- **能力是可选的**：图库、网络存储、网络资源、网络电视、网络影院五个模块可独立拾起或放下，侧边栏与全局搜索随之收放。
- **智能是可选、可换、可核查的**：图片理解在本机完成（Vision / SigLIP2 / YOLO），大模型可以接云端，也可以接本机的 Ollama / LM Studio；助手通过 73 个本地工具真正去检索、整理和播放，动数据前先确认，默认不上传原图。

## 五个模块

| 模块 | 一句话 | 能做什么 |
| --- | --- | --- |
| **图库** | 所有内容的基础 | 时间轴（年 / 月 / 所有照片）、相簿与文件夹、人物、场景、地点与地图、关键词；正方形 / 完整宽高比 / 瀑布流 / 列表四种网格；筛选排序、框选、批量操作、编辑、压缩导出、打印、保险库备份与校验、图库体检与重复项 |
| **网络存储** | 网盘与 NAS 直读 | SMB / WebDAV / 阿里云盘 / 百度网盘 / 夸克网盘 / 115 网盘；目录树浏览、缩略图与 EXIF 缓存、媒体类型 / 场景 / 相簿视图、网盘自带影院 |
| **网络资源** | 站点聚合 · 海报墙 | 苹果 CMS 系影视接口与网页源统一导入；海报墙、分类筛选、详情页、演员页、站内搜索 |
| **网络电视** | 直播 · 节目单 · 回看 | IPTV 播放列表、频道墙与分组、EPG 节目单、直播与回看、收藏与开播提醒 |

> 五个模块在后端由同一套「源 → 内容 → 播放目标」契约驱动，因此图库、网盘、影院、电视共用同一个查看器与播放内核。AI 不单独成模块：端侧理解横跨图库，助手工具覆盖影院、网络资源、网络影院与电视。

## 核心能力

**浏览与整理**

- 年 / 月拼图总览、所有照片网格、相簿 / 文件夹 / 智能相簿、媒体类型与更多项目。
- 排序（日期、标题、文件名、大小、类型、相机、地点、时长）、筛选（收藏 / 已编辑 / 照片 / 视频 / 截屏 / 未加入相簿）、关键词筛选。
- 框选、方向键导航、可开关的卡片文字浮层、右键菜单作用于整个选区。
- 拖拽导入、SHA-256 查重、导入后校验；最近删除与恢复、图库级撤销 / 重做。

**端侧智能与 AI 助手**

- **本地图像理解（不上传）**：Vision 做精确 OCR、条码 / 二维码、人脸与人体姿态、文档分割与裁切，并在没有本地模型时兜底场景分类；SigLIP2 提供零样本中文标签与 768 维图像向量，YOLO11n 补充 80 类物体；结果写入当前图库，用于场景页、关键词、相似照片与全文搜索。
- **本地模型可按需安装**：SigLIP2 约 350MB（图像编码器 92MB + 文本编码器 259MB），从国内镜像下载、SHA-256 校验、编译成 Core ML 后原子替换，失败自动回滚；支持从本地目录离线导入、随时停用或删除。未安装或旧系统上自动回退 Apple Vision，不会让功能整块消失。
- **大模型可云端、可本机**：预置 DeepSeek / Kimi / GLM / 通义千问 / 豆包 / OpenAI 与任意 OpenAI 兼容端点；也可以一键探测本机的 Ollama、LM Studio，模型自己选，数据不出本机。API Key 只进钥匙串。
- **Agent 真的会做事**：73 个本地工具覆盖图库检索、相册 / 文件夹、评分 / 关键词 / 标题、压缩 / 美化、删除恢复，以及影院刮削匹配、网络资源、网络影院与电视直播；支持快速 / 标准 / 深度三档、多轮工具调用、执行轨迹与失败回传。
- **动手前先问一句**：35 个写工具按「每次确认 / 仅高风险 / 自动应用」审批，一次回复里的多个动作合并成一个确认框；有操作意图但模型没调用工具时，会明确提示「本次没有执行」，不接受口头完成。
- **图片默认不出本机**：默认只把元数据与本地标签 / OCR 发给模型；要发原图需要手动开启，开启后也只会发送长边 1024 的 JPEG，默认最多 4 张。
- 还有：人物聚类、地点聚类与「地点 + 连续日期」行程段，模糊 / 大视频 / 相似照片体检，以及「画面统计 → 调整理由」的本地美化建议。

> 当前边界：内置 GGUF 本地语言模型尚未接入（用 Ollama / LM Studio 代替）；没有 Skill 市场、MCP Server 与多 Agent 编排；模型回复是整段返回，不是流式输出。

**观看与输出**

- 窗口内查看器与全屏查看器共用一套翻页、缩放、胶片条与元数据面板。
- 自研播放内核：HDR、倍速不变调、多音轨即时切换、字幕、按片源帧率匹配刷新率；按住快进 / 快退逐级加速。
- 编辑、批量压缩导出、打印、幻灯片与回忆影片。

**搜索**

- 统一搜索覆盖图库、网盘、影院、网络影院、电视、资源六个来源，结果按来源与类型分组。
- 图库来源同时匹配文件名、标题、相簿 / 文件夹、官方关键词、端侧场景标签与 OCR 文本；百万级图库从索引取全量命中，不做条数截断。

**能力状态（按代码与实测整理）**

- **已实测通过**：AC-3 / E-AC-3 / ALAC 直通；杜比视界 RPU 在 HDR 屏保留、SDR 屏经 libplacebo 映射；4K 色调映射约 1.55× 实时；SMB / WebDAV 真实片源起播与拖动；离线转码按真实帧率降档；HEVC 重编码输出 `hvc1` / Main10。
- **待实测（暂不按「完整支持」宣传）**：E-AC-3 JOC / Atmos 元数据是否保留、`hevc_videotoolbox main10` 编码速度、`-hwaccel videotoolbox` 的净收益、多 variant HLS 切换开销、弱网 `NWPathMonitor` 时序、HDR10+ 动态元数据、`yadif_videotoolbox` 与 `bwdif` 的画质差异、端到端首段与卡顿基线。
- **尚未实现**：HDR 输出计划层（HDR 判定仍分散在播放器与 `StreamPlanner`）、ffmpeg 硬件解码、多码率 ABR、云端字幕自动挂载、Atmos 对象层渲染、HDR10+ 动态元数据。

## 设计语言

拾光的视觉从一句品牌隐喻长出来：**被拾起的光**。

- 品牌色是一段暖到冷的光谱：琥珀 → 珊瑚 → 粉 → 紫 → 青，用于图标光环、标题渐变与装饰线条。
- 强调色提供 11 种选择（系统 / 蓝 / 靛蓝 / 紫 / 粉 / 橙 / 金 / 绿 / 薄荷 / 青 / 石墨），并自动为浅色强调配深色前景。
- 主题（外观 + 强调色）**按图库保存**：切到另一个图库，界面跟着换一套光。
- 首次建库的引导页即是一场品牌叙事：外观弧、强调色光点与「拾光」徽标围成一圈年轮，下方是「历史 → 此刻 → 未来」的光线。

细化的色板、字号、间距、组件与动效规范见 [UI 设计及标准](docs/ui-design-system.md)。

## 技术架构

| 层 | 目标 | 职责 |
| --- | --- | --- |
| `LumaCore` | 无 UI 依赖 | 网格布局算法、缩略图档位、感知哈希、美化建议 |
| `PlaybackCore` | 播放内核 | 时间轴、片源计划、AVPlayer 引擎、ffmpeg 管道、字幕解析 |
| `LumaContentCore` | 内容契约 | 源、内容引用、播放目标、搜索、任务、错误与进度接口 |
| `Luma` | 应用 | SwiftUI + AppKit 界面，状态树、服务层与各模块实现 |

- 纯 SwiftPM，零第三方依赖；macOS 14+，链接系统 `libsqlite3`、`Photos`、`NetFS`。
- 数据层：自有 `MetadataStore`（SQLite）+ 系统图库只读索引 `SystemIndex`（直连 `Photos.sqlite`）。
- 大图库不为视图层 `filter` / `sorted`：范围、筛选、排序下推 SQLite，按 600 张一页的窗口滚动加载。
- 并发模型：主线程只跑界面与状态，扫描、索引、解码、网络请求在后台任务里完成。
- AI：端侧 `Vision` + Core ML（SigLIP2 / YOLO11n）负责图像理解；`AIProviderClient` 走 OpenAI 兼容协议，`AIToolRegistry` 按模块注册 73 个工具。
- AI 结果只写补充数据：本地库 `asset_analysis`、系统库 `system_analysis`、网盘 `cloud_assets`；模型安装在应用目录，API Key 只进钥匙串，都不进图库、不改原图。

构建、目录结构、数据模型、查询与打包流程见 [代码开发文档](docs/development.md)。

# 构建（默认 release），产物 Luma.app

swift run LumaCoreChecks
