# 拾光 Luma · UI 设计及标准

> 适用于 macOS 14+ 的 SwiftUI 界面。所有数值取自 `Sources/Luma/Support/LumaDesign.swift` 与各视图实现，新增界面请沿用本规范。

---

## 1. 设计原则

1. **光优先于框**：用光晕、渐变与材质表达层级，而不是堆叠边框与阴影。
2. **一屏一主任务**：每个页面只有一个视觉主动作（主按钮 / 主网格 / 主播放区）。
3. **规整**：4pt 基准间距、统一的圆角与描边、统一的字号阶梯。
4. **安静**：默认低对比装饰，悬停才加强；动效短、轻、可预期。
5. **可读**：任何颜色组合都要在浅色与深色两套背景下单独验证。

## 2. 色彩

### 2.1 品牌色（LumaBrand）

| Token | RGB | Hex | 用途 |
| --- | --- | --- | --- |
| coral | 255, 143, 122 | `#FF8F7A` | 渐变暖端、历史段光线 |
| amber | 255, 196, 107 | `#FFC46B` | 图标光环、高光 |
| mint | 125, 247, 191 | `#7DF7BF` | 状态点缀 |
| cyan | 94, 217, 255 | `#5ED9FF` | 渐变冷端、未来段光线 |
| violet | 168, 140, 255 | `#A88CFF` | 主品牌紫、此刻段 |
| pink | 255, 122, 199 | `#FF7AC7` | 标题渐变中段 |

- 主渐变 `LumaBrand.gradient`：`amber → coral → pink → violet → cyan`（从左到右）。
- 图标细环 `LumaBrand.ring`：`coral → amber → mint → cyan → violet → pink → coral` 的角度渐变。
- 文字渐变 `textGradient(dark:)`：深色模式用品牌渐变；浅色模式换成同色相的压深版本，避免在浅底发白。

### 2.2 强调色（AppAccent，11 种）

系统 / 蓝 / 靛蓝 / 紫 / 粉 / 橙 / 金 / 绿 / 薄荷 / 青 / 石墨。

- 强调色是**唯一**的交互强调来源：选中态、主按钮、进度、聚焦描边都用它。
- 自动前景：当强调色亮度 > 0.62（金 / 薄荷等），填充上的文字改用 `black.opacity(0.85)`；否则用白色。
- 浅色页面里把强调色当正文文字时压深一档（`readableAccent`），保证对比度。

### 2.3 语义色

| 语义 | 取值 |
| --- | --- |
| 主文字 | `Color.primary` |
| 次文字 | `Color.secondary` |
| 辅助文字 | `Color.tertiary` |
| 分隔线 | `Color.primary.opacity(0.06–0.12)` |
| 卡片底（深 / 浅） | `primary.opacity(0.05)` / `primary.opacity(0.035)` |
| 悬浮材质 | `.ultraThinMaterial` |
| 危险 | 系统红，仅用于删除与不可恢复操作 |

### 2.4 深浅色

- 不硬编码背景色；跟随系统外观，或用户选择的浅色 / 深色 / 自动。
- 深浅两套必须分别检查：浅色下减弱白描边、加深文字；深色下提高光晕透明度、降低纯白面积。
- 品牌首屏例外：允许固定深空背景，但「拾光」标题与所有文案必须自证对比度。

## 3. 字体与字号

系统字体（SF Pro / 苹方），数字与时间用等宽。

| 场景 | 字号 | 字重 |
| --- | --- | --- |
| 页面大标题 | 21 | bold |
| 卡片标题 / 分区标题 | 13 | semibold |
| 正文 | 11.5 – 12 | regular |
| 控件文字（胶囊 / 按钮） | 11.5 – 12 | semibold |
| 辅助说明 | 10 – 10.5 | regular |
| 角标 / 计数 | 9 – 9.5 | regular，等宽 |
| 品牌页主标题 | 118（画布内） | 苹方 W6 |

- 中文标题字距紧凑（`tracking -0.01`）；英文品牌字（SHIGUANG）用大字距（13pt 间距）。
- 行距：多行说明 `lineSpacing 2`；紧凑列表默认。

## 4. 间距、尺寸与圆角

- **基准 4pt**；常用 6 / 8 / 10 / 12 / 14 / 20 / 26。
- 页面内容左右留白：26（照片网格与卡片墙）；卡片内边距 12–14。
- 行高：紧凑行 26 / 标准行 34 / 表单行 40 / 工具栏按钮 24–26。
- 圆角：胶囊 999 / 小控件 6–8 / 卡片 10–12 / 大面板 16。
- 描边：0.5–0.9pt，用 `primary.opacity(0.06–0.12)` 或白色 `opacity(0.14)` 的渐变描边；避免纯黑纯白细线。

## 5. 层级与材质

1. **窗口环境光**：底部铺一层窗口底色，叠两团强调色光晕与暗角（`LumaAmbientBackground`）。
2. **玻璃面板**：控制台、浮动条用 `.ultraThinMaterial` + 16 圆角 + 渐变描边。
3. **卡片**：低透明底色 + 0.5 描边；悬停时描边转强调色、轻微放大（1.015–1.02）与投影加深。
4. **浮层**：元数据浮层、提示条用更实的材质与更强的投影，保证压在照片上也清晰。

投影统一：`black.opacity(0.06–0.20)`，半径 4–14，y 偏移 2–5；不要在同一个元素上叠两层以上投影。

## 6. 图标

- 统一使用 SF Symbols；尺寸：行内 11.5 / 工具栏 13 / 模块标识 16 / 空态 40（ultraLight）。
- 模块图标与 tint：图库（照片）、网络存储（网盘）、网络资源（站点）、网络电视（直播）、网络影院（影视）。
- 图标与文字间距 7–9；图标列宽固定，保证侧边栏纵向对齐。

## 7. 组件规范

### 7.1 侧边栏

- 分区标题：13 semibold + 模块色竖条；悬停显示「更多」与折叠按钮；标题本身可点击进入二级总览。
- 源行：图标 + 名称 + 状态点（在线 / 未连接）；整行可拖拽排序、右键管理。
- 默认折叠：媒体类型、场景、更多项目；折叠状态随图库保存。

### 7.2 照片网格（四种形式）

| 形式 | 规则 |
| --- | --- |
| 正方形 | 等宽正方形裁剪，行列对齐 |
| 完整宽高比 | 按原始比例分组，行高统一，文件名居中于图下 |
| 瀑布流 | 等宽多列、列内高度自适应；卡片比其它网格大 1.5 倍，带常驻投影 |
| 列表 | 缩略图 + 文件名 + 日期 / 尺寸 / 大小 |

缩放：滑杆、`⌘+ / ⌘- / ⌘0`、触控板捏合三路同源；人物与位置卡片墙共用同一套缩放控件。

### 7.3 工具栏与播放舱

- 顶栏左侧：返回、页面标题与计数；中间：分段 / 类型；右侧：搜索、布局与筛选。
- 播放舱：标题信息行 + 进度条 + 双时间 + 音量；传输按钮 24–26pt，图标不描边，悬停给底色。
- 快进 / 快退：单击跳一步，按住不放按递减间隔重复，步长逐级加速，到达上限后匀速。

### 7.4 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | 强调色胶囊，高度 40–44，白色或深色自动前景 |
| 次按钮 | 玻璃底 + 描边，同高 |
| 图标按钮 | 26pt 方 / 圆角 7，悬停加底色 |
| 胶囊筛选 | 高 26–28，选中填强调色，未选低透明底 |

### 7.5 状态与反馈

- 加载：骨架 + mini 转圈；超过 1 秒显示原因文案。
- 空态：图标 + 一句解释 + 一个可执行入口，不写「暂无数据」。
- Toast：底部居中，2–3 秒自动消失，不遮挡主操作。
- 破坏性操作：菜单项红色 + 二次确认；可撤销操作提供撤销。

## 8. 动效

| 场景 | 参数 |
| --- | --- |
| 悬停反馈 | `easeOut 0.12` |
| 胶囊 / 选中切换 | `snappy 0.18` |
| 覆盖层开合（查看器 / 编辑器） | `motion.overlay`（约 0.3 弹簧） |
| 光晕呼吸 | 4–6s `repeatForever(autoreverses: true)` |
| 光谱自转 | 12s 线性 |
| 刻度环 | 64s 反向匀速 |
| 品牌入场 | 圆环旋入 → Logo 弹出 → 光点聚拢，分段延迟 80–120ms |

原则：动效只用于「状态改变」与「品牌叙事」；列表滚动、输入、翻页不加装饰动画。尊重「减弱动态效果」：关闭自转与呼吸，保留淡入淡出。

## 9. 可读性与无障碍

- 文字与背景对比度 ≥ 4.5:1；浅色强调色上必须换深色前景。
- 关键控件有 `help` 文案，包含快捷键；图标按钮必须有 `accessibilityLabel`。
- 键盘可达：`⌘F` 搜索、方向键导航、`Esc` 清除 / 关闭、空格打开查看器。
- 不用颜色单独表达状态：在线 / 离线同时给文字或形状。
- 明暗切换、强调色切换后重新验证：卡片描边、分隔线、禁用态。

## 10. 品牌页（建库引导）规范

- 布局：居中单列，最大宽度 500–560；首屏是圆环徽标，第二屏是能力选择。
- 圆环：外径 336，内径比 0.55 / 外径比 0.93 做命中区，三段弧分别代表浅色 / 深色 / 自动；强调色光点沿轨道排布，悬停显示颜色名。
- 徽标：190pt 中心区，浅色用暖白玻璃、深色用强调色浸染的深空玻璃，保证「拾光」两个字始终最高对比。
- 底部：版本、无需账号、本地运行与「退出拾光」同一行，样式为 10.5pt 次级文字。
- 第二屏：能力以「光串」呈现（细绳 + 珠子），珠子 54pt，命中区覆盖整颗珠子与标签。

## 11. 交付检查清单

- [ ] 浅色 / 深色 / 自动三种外观都看过
- [ ] 十一种强调色中至少抽查金 / 薄荷 / 石墨三种极端亮度
- [ ] 最小窗口尺寸下不裁切、不重叠，必要时可滚动
- [ ] 所有数字与时间用等宽，所有空态有出口
- [ ] 动效可被「减弱动态效果」关闭
- [ ] 文案使用「拾起 / 放下」口径，不出现「开启模块」之类混用
