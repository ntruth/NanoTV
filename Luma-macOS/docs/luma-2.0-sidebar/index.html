拾光 2.0 · 左侧栏只做新增

这一版不重做侧边栏。分区头、行高、图标列、缩进、悬停高亮、分区收起、相簿层级全部沿用现有 SidebarView；只在现有分区之后插入三个新模式分区。

保持不动 拾光、系统图库、网络存储、网络资源；现有行高 27、图标 16 / 列宽 20、圆角 8、箭头列 12 + 间隙 3。
只新增 网络影院、网络电视、本地磁盘。行结构与网络存储 / 网络资源完全一致，不引入新控件。

新增分区的行

  • 网络影院：本地影院、家庭 NAS · 影院、在线电影源（待接入）、接入电影源…
  • 网络电视：家庭 IPTV（可展开 央视 / 卫视 / 体育 / 电影）、备用直播源、添加 M3U…
  • 本地磁盘：Macintosh HD、素材盘、备份卷（未挂载）、挂载文件夹…
  • 三个分区都排在现有「网络资源」之后，沿用同一套分区头与行样式；不新增顶部模式胶囊。

交互逻辑

  • 点击网络存储 / 网络影院 / 网络资源 / 网络电视 / 本地磁盘：只切换右侧浏览内容与面包屑，不改变当前图库；顶部只更新当前范围的工具项。
  • 点击系统图库 / 链接图库：切换当前图库会话；单库重构后分区文案由「系统图库」改为「链接图库」，行结构不变。
  • 悬停行：显示「…」更多菜单与拖拽手柄；源行可在同一分区内拖动排序。
  • 右键行：打开、刷新、编辑接入、断开；图库行只提供打开 / 固定。
  • 分区头：点击展开 / 收起；悬停出现「…」与收起按钮；电视分组、云盘目录、影院片单沿用现有 14px 层级缩进。

只读语义

  • 网络存储、影院、资源、电视、本地磁盘是只读浏览源；写入动作仍只落在当前图库。
  • 本地磁盘的「添加到图库」是唯一显式写入入口，且只在当前图库可写时可用。
  • 电视直播没有续播语义；影院在线源与本地 / 网盘影院共用右侧详情与播放链路。
