## 1. 六种模式与写入会话语义

### 1.1 模式定义

| # | 模式 | 内容来源 | 左侧主导航分区 | 能力 | 右侧内容示意 |
| --- | --- | --- | --- | --- | --- |
| 1 | 图库 | 当前图库 + 链接图库（其他 `.photoslibrary` 图库） | 当前图库、链接图库 | 当前图库可写；链接图库切换后成为当前会话 | 照片网格、精选集、日期分组 |
| 2 | 网络云盘 | SMB、WebDAV、阿里云盘、百度网盘、夸克、115 | 网络云盘 | 只读浏览 | 目录树 + 文件列表 |
| 3 | 网络影院 | 本地 / 网盘文件刮削，在线电影源 | 网络影院 | 只读浏览 | 海报墙、影片详情、播放线路 |
| 4 | 网络资源 | 影视站点源：分类、详情、分集、续看 | 网络资源 | 只读浏览 | 源卡片、榜单、续看 |
| 5 | 网络电视 | M3U / IPTV 直播源、频道分组、EPG | 网络电视 | 只读浏览；直播无续播语义 | 频道列表 + 现在 / 下一档 + EPG |
| 6 | 本地磁盘 | 外接磁盘 / 文件夹（只读或可写媒体源） | 本地磁盘 | 只读浏览；写入需显式“添加到图库” | 卷列表 + 文件夹 / 文件表格 |

### 1.2 唯一写入会话

1. **当前图库是唯一拥有写入会话的源。**
   - 当前图库卡片、模式条会话标签、右侧说明卡同时展示当前图库名称与能力（可写 / 只读）。
   - 导入、编辑、删除、评分、新建相簿等写入动作只允许落在当前图库。
   - 当当前图库为只读（例如原生库未授权 PhotoKit）时，图库工具栏的“导入 / 新建相簿”禁用，内容区写入入口显示禁用原因。
2. **链接图库是图库会话的另一种载体，不是挂载盘。**
   - 链接图库（其他 `.photoslibrary` 图库）点击后不会立即进入，而是弹出“切换到该图库？”确认层。
   - 确认后整体替换会话：图库名称、路径、时间轴、相簿、精选集、智能整理一起切换；可写能力按目标库重新计算（Managed 可写，Native 取决于 PhotoKit 授权），不是一律只读。
   - 取消、点击遮罩或按 `Esc`：当前图库、侧栏选中态、右侧内容均不改变。
3. **网络云盘 / 网络影院 / 网络资源 / 网络电视 / 本地磁盘是只读浏览源。**
   - 点击这些条目只切换右侧浏览内容与顶部模式栏，不改变当前图库、不重建图库会话。
   - 顶部显示常驻提示条：**“只读浏览 · 当前图库不变”**；同时出现轻提示。
   - 上传、删除、重命名等写入按钮在只读浏览下禁用，并在禁用态说明原因。
4. **例外只有一条显式写入路径：** 本地磁盘的“添加到图库”。它需要用户明确点击，且当前图库必须可写；把目录加入图库后，后续整理仍发生在当前图库会话中。

### 1.3 激活策略

| 触发对象 | 呈现 | 是否确认 | 会话变化 | 结果 |
| --- | --- | --- | --- | --- |
| 当前图库下的条目（图库 / 精选集 / 固定 / 媒体类型 / 更多项目 / 场景 / 相簿） | 直接进入 | 否 | 不替换会话 | 右侧切到该条目，面包屑与说明卡更新；筛选 / 搜索可联动 |
| 链接图库条目（旅行图库 / 工作室归档） | 轻量确认层 | 是 | 确认后替换整个图库会话 | 当前图库卡、模式条会话标签、图库标题、统计与可写能力更新 |
| 网络云盘条目 | 直接切换右侧浏览 | 否 | 不变化 | 顶部模式变为网络云盘，显示只读提示条 |
| 网络影院条目 | 直接切换右侧浏览 | 否 | 不变化 | 顶部模式变为网络影院，显示只读提示条 |
| 网络资源条目 | 直接切换右侧浏览 | 否 | 不变化 | 顶部模式变为网络资源，显示只读提示条 |
| 网络电视条目 | 直接切换右侧浏览 | 否 | 不变化 | 顶部模式变为网络电视，显示只读提示条 |
| 本地磁盘条目 | 直接切换右侧浏览 | 否 | 不变化 | 顶部模式变为本地磁盘，显示只读提示条 |
| 六个模式胶囊 | 切换模式 | 否 | 不变化（图库模式下仅恢复当前会话） | 左侧树展开对应分区、顶部栏替换专属控件、右侧内容切换、说明抽屉更新 |
| 返回图库（提示条 / 胶囊 1） | 切回图库 | 否 | 不重建会话 | 恢复当前图库与其上次选中条目 |

> 记忆规则：每个模式记住自己的最后浏览节点与视图（网格 / 列表）；切换模式不会重置当前图库，也不会把只读源“提升”为图库。

### 2.3 单行元素（从左到右）

1. **拖拽手柄**：悬停 / 键盘聚焦时出现；所有行都有，可在同一父级内调整顺序。
2. **展开箭头**：有子级时显示；展开状态旋转 90°；无子级时保留占位但不可见。
3. **图标**：16px 内联 SVG，单色，选中时使用当前模式强调色。
4. **主文案 + 次文案**：主文案 12px；次文案 9.5px，展示路径 / 数量 / 协议 / 状态说明。
5. **角标**：当前、可写、只读、在线、需授权、加载中、空、错误、未挂载、数量、固定等。
6. **“…”更多按钮**：悬停 / 聚焦时出现，打开与右键相同的条目菜单。

行高：最小 29px（双行内容约 29–31px）；圆角 8px；行内边距 3px 7px；子级每层缩进 14px。

## 3. 左侧栏交互清单

### 3.1 基本操作

| 操作 | 触发 | 结果 | 边界 / 例外 |
| --- | --- | --- | --- |
| 单击当前图库条目 | 图库分区任意行 | 切换到该条目；右侧标题、面包屑、筛选 / 搜索联动；当前图库不变 | 不弹确认；不重建会话 |
| 单击链接图库 | 链接图库分区行 | 打开“切换到该图库？”确认层；显示当前 → 目标、能力变化、会话替换说明 | 取消 / 遮罩 / `Esc` 不改变任何状态 |
| 单击只读来源 | 云盘 / 影院 / 资源 / 电视 / 本地磁盘行 | 切换模式与右侧浏览内容；显示只读提示条与轻提示 | 不替换当前图库；不弹确认 |
| 双击 | 任意有子级的行 | 展开 / 收起子级 | 不改变选中源；不与单击冲突 |
| 悬停 | 任意行 | 行背景提亮；显示拖拽手柄与“…” | 选中行保持强调色；工具按钮淡入 |
| 展开 / 收起 | 箭头、双击、`→` / `←` | 子级以 220ms 高度动画展开 / 收起；箭头旋转 | 无子级的行不响应 |
| 分区折叠 | 分区标题 | 整个分区收起 / 展开；分区计数仍可见 | 分区状态在本次会话内保留 |
| 拖拽 | 拖拽手柄或行本身 | 在同一父级内调整顺序；提示“已调整同级顺序（仅本机偏好）” | 不跨分区 / 不跨父级；不改变数据与会话 |
| 右键 | 行 | 在行下方打开条目菜单 | 菜单与“…”完全一致 |
| 更多菜单 | 悬停后的“…” | 打开条目菜单 | 菜单可通过 `Tab` 聚焦 |
| 键盘 | 行聚焦 | `Enter` / `Space` 激活；`→` 展开；`←` 收起 | 行可被 `Tab` 聚焦 |
| 搜索 | 顶部搜索框 / `/` | 过滤当前模式内容，不搜索整个侧栏 | 无结果时显示空态；清除后恢复 |

### 3.2 条目菜单

| 菜单项 | 当前图库行 | 只读来源行 | 行为 |
| --- | --- | --- | --- |
| 打开 | 可用 | 可用 | 等同单击该行 |
| 刷新 | 禁用（当前库由“切换图库 / 刷新”统一处理） | 可用 | 行进入加载态，约 900ms 后恢复在线；显示轻提示 |
| 编辑接入… | 禁用 | 可用 | 打开接入设置（原型为提示） |
| 固定到顶部 / 取消固定 | 可用 | 可用 | 置顶并追加“固定”标识；再次点击取消 |
| 断开连接 | 禁用 | 可用 | 将行置为错误态“已断开”；当前图库不变 |

菜单为示例交互，未实现真实网络请求；所有破坏性操作只影响当前原型的可视化状态。

### 3.3 加载 / 空 / 错误 / 授权失效

| 场景 | 交互路径 | 原型结果 |
| --- | --- | --- |
| 加载中 | 展开网络云盘，点击“百度网盘” | 右侧切换为骨架加载卡；侧栏保持“加载中” |
| 空 | 点击“夸克网盘” | 右侧显示空态卡，提供“重新扫描”；重新扫描后恢复在线 |
| 错误 | 点击“115 网盘” | 右侧显示连接失败，提供“重试连接”；重试成功后恢复在线 |
| 需授权 | 点击“阿里云盘” | 右侧显示授权失效，提供“重新授权”；授权后恢复在线 |
| 需授权（电视） | 工具菜单切到“备用直播源”或点击该行 | 右侧替换为授权卡；分组、EPG、回看、收藏按钮禁用 |
| 未挂载 | 点击“移动硬盘” | 右侧显示未挂载卡，提供“挂载卷”；挂载后显示目录与状态卡 |
| 只读浏览 | 点击任一非图库来源 | 顶部出现“只读浏览 · 当前图库不变”；上传 / 写入按钮禁用 |

## 4. 顶部栏逐模式清单

顶部栏分为三层，三层始终同时存在：

1. **窗口层（titlebar）**：红绿灯、侧边栏折叠、应用标识、模式标签、全局搜索、视图切换、更多、主题。
2. **模式条（mode strip）**：6 个模式胶囊 + 当前写入会话标签 + 交互说明抽屉开关。
3. **上下文栏（mode toolbar）**：面包屑 + 当前模式专属控件。

### 4.1 窗口层共用项（所有模式一致，顺序固定）

| 顺序 | 控件 | 图标 / 文字 | 行为 | 禁用条件 |
| --- | --- | --- | --- | --- |
| 1 | 红绿灯 | 红 / 黄 / 绿圆点 | 仅装饰，模拟 macOS 窗口按钮 | 始终不可交互 |
| 2 | 侧边栏折叠 | 分栏图标 | 隐藏 / 恢复 258px 侧栏；`aria-expanded` 同步 | 无 |
| 3 | 应用标识 | “拾”图标 + “拾光 Luma 2.0” | 仅标识 | 无 |
| 4 | 模式标签 | 当前模式名称胶囊 | 跟随模式与强调色变化 | 无 |
| 5 | 全局搜索 | 放大镜 + 输入框 + `/` | 过滤当前模式内容；`/` 聚焦；占位文案随模式变化 | 无；无结果时显示空态 |

## 5. 端到端交互流程

### 5.1 切换到链接图库

1. 在图库模式左侧“链接图库”分区点击“旅行图库”。
2. 出现轻量确认层：
   - 标题：“切换到该图库？”
   - 左侧：当前图库“家庭图库”，能力“可写 · 本地图库”。
   - 右侧：目标“旅行图库”，能力“可写 · 本机图库”（示例；原生图库未授权时显示“只读 · 能力受限”）。
   - 说明：确认后替换整个图库会话；云盘、影院、资源、电视与本地磁盘浏览源不受影响。
3. 选择取消、点击遮罩或按 `Esc`：无任何状态变化。
4. 确认“切换并进入”：
   - 当前图库卡更新为“旅行图库”，路径变为 `smb://nas.local/Photos/2026`，能力变为“只读”。
   - 模式条写入会话标签同步为“旅行图库 · 只读”。
   - 图库标题、统计、精选集与时间轴切换到链接图库；图库工具栏“导入 / 新建相簿”禁用。
   - 侧栏“旅行图库”出现“当前”角标。
5. 通过当前图库卡的“切换图库”按钮选择“家庭图库”，再次确认后恢复可写会话。

### 5.2 接入 / 浏览网络云盘

1. 点击模式条“网络云盘”胶囊，或直接点击侧栏“网络云盘”下的挂载。
2. 顶部出现“只读浏览 · 当前图库不变”，并出现轻提示；当前图库卡不变。
3. 点击“家庭 NAS”：
   - 右侧显示目录树（Photos 2026 / 海岸线 / 城市夜景 / 家庭视频 / 电影库 / 云备份）。
   - 文件列表可刷新、切换网格 / 列表；面包屑显示当前目录。
4. 点击“阿里云盘”（需授权）：
   - 右侧显示“需要重新授权”；点击“重新授权”后行角标变为“在线”，仍不改变图库。
5. 点击“115 网盘”（错误）：
   - 显示“连接失败”；点击“重试连接”，加载约 900ms 后恢复在线。
6. 点击“百度网盘”（加载中）：显示骨架加载卡；点击“夸克网盘”（空）：显示空态与“重新扫描”。
7. 点击工具栏“上传”：不可点击，标题说明原因；点击“刷新索引”：进度从 12% 到 100%。
8. 点击“返回图库”或模式胶囊“图库”：回到当前图库，不重建会话。

### 5.3 浏览与打开网络影院影片

1. 点击“网络影院”模式胶囊；左侧自动展开“网络影院”分区。
2. 选择“本地影院”：
   - 顶部工具栏显示筛选、排序、扫描、刮削状态；右侧显示海报墙与 Hero 影片。
3. 点击筛选“剧集”：海报墙只保留剧集；“待识别”节点会显示待刮削状态卡。
4. 点击“扫描”：状态从 0% 到 100%，完成后“待识别”归零，侧栏角标变为“已刮削”。
5. 点击任一海报：打开详情 / 播放提示；点击“线路 1 / 线路 2 / 预告片”切换高亮线路。
6. 点击“继续播放”：显示播放提示。过程中不产生图库写入；图库会话始终不变。
7. 点击“返回图库”或胶囊 1：回到当前图库。

### 5.4 网络资源分类、详情与续看

1. 点击“网络资源”胶囊，左侧自动展开站点源。
2. 点击“站点源 → 星海资源”：顶部源标签变为“星海”，右侧源卡片高亮；当前图库不变。
3. 点击分类菜单“最新 / 热门 / 评分”：标签更新；聚合内容仍为只读。
4. 点击榜单条目：打开聚合资源详情提示；点击“续看”卡片：从上次进度继续。
5. 点击侧栏“备用源”（维护）：右侧显示错误卡，可“重新聚合”；不影响当前图库。
6. 续看只记录播放进度与集数，不保存站点直链；切换源不改变当前图库。

### 5.5 网络电视直播与 EPG

1. 点击“网络电视”胶囊，左侧自动展开“家庭 IPTV”。
2. 在频道列表点击“湖南卫视”：
   - 频道行高亮；“现在”更新为“你好星期六”，频道角标更新为“湖南卫视”，下一档更新。
   - 出现轻提示“已切换到湖南卫视”。
3. 点击分组“体育”：频道列表只保留体育分组；工具栏分组标签同步为“体育”。
4. 点击“刷新 EPG”：右上方日期文案更新为“EPG 同步于 HH:MM”。
5. 点击“回看”：开启 / 关闭 7 天回看偏好；点击“收藏”：收藏当前频道。
6. 从播放列表菜单切到“备用直播源”：右侧显示授权卡；分组、EPG、回看、收藏按钮禁用。重新授权后恢复。
7. 直播无总时长、无续播、无片尾行为；频道切换只改变播放目标，不改变图库。

### 5.6 挂载本地磁盘与添加到图库

1. 点击“本地磁盘”胶囊，左侧自动展开卷列表。
2. 点击“移动硬盘”（未挂载）：右侧隐藏目录与状态卡，显示“卷未挂载”。
3. 点击“挂载卷”：卷恢复在线，显示目录表、扫描与监听状态；当前图库仍不变。
4. 点击工具栏“卷”切换“素材盘 / 备份卷”：标题、路径、卷高亮与能力同步；只读卷与可写卷分别显示。
5. 点击“扫描”：进度 0% → 100%，更新时间与文件数；点击“监听”：暂停 / 恢复 FSEvents。
6. 点击“添加到图库”：
   - 当前图库为可写：模拟把目录加入家庭图库。
   - 当前图库为只读（如原生库未授权）：提示无法添加。
   - 这是本地磁盘唯一会写入图库的入口，且必须显式触发。

### 5.7 返回图库

- 顶部只读提示条右侧“返回图库”；
- 或模式条“图库”胶囊；
- 或 `1` 快捷键。

结果：回到当前图库及其上次选中条目；不清空当前图库，不重建写入会话。

### 6.5 排版与动效

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif`。
- 图标：全部为内联 SVG 或文字几何形，不使用 emoji，不引用外部图片 / 字体 / CDN。
- 展开动画：`grid-template-rows: 0fr → 1fr`，约 220ms，`cubic-bezier(.22,.8,.22,1)`。
- 内容切换：淡入 + 轻微位移，约 220ms。
- 抽屉 / 侧栏：宽度过渡约 220ms。
- 支持 `prefers-reduced-motion`：动效缩短到近零。
- 数字使用等宽数字特性，便于对齐容量、数量与时间。

### 6.6 布局与可访问性

- 最小支持宽度 **1180px**；`body` 禁止横向滚动，页面在 1180 / 1440 实测无横向溢出。
- 窗口层、模式条、上下文栏固定；侧栏树、内容区、说明抽屉各自内部滚动。
- 1180px 下上下文栏按钮允许换行，但不出现横向滚动条。
- 主要控件均可 `Tab` 聚焦；侧栏行支持 `Enter` / `Space` 激活，`←` / `→` 展开收起。
- 快捷键：`1`–`6` 切模式，`/` 聚焦搜索，`Esc` 关闭弹层 / 菜单。
- 侧栏行、模式胶囊、视图切换、开关与弹层均带 `aria-selected` / `aria-pressed` / `aria-expanded` / `role` 等语义。
