# 更新日志

本文件记录拾光 Luma 面向用户的版本变更；完整发布说明见 [Releases](https://github.com/houshanren/luma/releases)。

## 2.1.0（2026-11-25）

承接 1.2.1（Build 7），本版为 2.1.0（Build 8），支持 macOS 14 Sonoma 及以上。2.1.0 的主线是「AI 与本地智能」：端侧图像理解统一到 Vision + SigLIP2 + YOLO，智能助手升级为可换模型、可本机运行的 Agent（73 个工具、三档模式、三种审批）；同时把图库搜索补成「关键词 / 相册 / 文件夹 / 人物 / 场景 / 地点 / 跨库全量不截断」，把编辑器补到专业工作流，并完成 `Sources/PhotosClone` → `Sources/Luma` 更名与文档体系重写。

### AI 与本地推理

- 工具总数 60 → 73：新增图库 7 个（`get_photo_info`、`list_keywords`、`list_people`、`library_overview`、`set_rating`、`set_flag`、`set_color_label`）与网络电视 6 个（`list_tv_sources`、`list_tv_channels`、`get_tv_guide`、`play_tv_channel`、`favorite_tv_channel`、`navigate_tv`）。
- 助手三档模式：快速（24 张候选 / ≤12 轮）、标准（40 张 / 80 轮）、深度（64 张 / ≥150 轮，上限 300）；历史轮数随模式调整。
- 写操作审批：每次确认 / 仅高风险 / 自动应用；35 个写工具，8 类高风险加清单删除动作；一次回复里的多个动作合并为一个确认框，取消会回传模型。
- 执行轨迹：工具回执合并、超过 4 步折叠；失败结果回传模型继续推理；统一任务条可取消。
- 助手面板重做：能力分区与示例、Markdown 渲染、耗时 / 工具轮数、重新生成、复制、面板缩放记忆、思考态。
- 模型接入：预置 DeepSeek / Kimi / GLM / 通义千问 / 豆包 / OpenAI / 自定义兼容端点；本机运行时自动探测 Ollama `11434` 与 LM Studio `1234` 并读取模型列表；支持连接测试。
- 视觉输入：默认关闭，只发元数据 + 端侧标签 / OCR；开启后发送长边 1024、质量 0.72 的 JPEG，默认最多 4 张（可调到 6）。
- 本地图像理解：Vision OCR（简中 / 英文、语言纠正）、条码 / 二维码、人脸 + 人体姿态、文档分割裁切；SigLIP2 零样本中文标签与 768 维向量；YOLO11n 80 类；发票 / 身份证规则、构图标签与证件照判定。
- 本地模型管理：清单多源、断点续传、SHA-256、ditto 解压、`.mlpackage` 编译 Core ML、空间预检、原子替换与失败回滚；支持离线目录导入、启停与卸载；未安装或旧系统回退 Apple Vision。
- 上下文与护栏：当前范围快照 + 40 张候选（按模式调整）、12 个标签、240 字 OCR；有操作意图但模型没调用工具时提醒一次，仍未执行则明确报错，不接受口头完成。
- AI 结果只写分析表（本地 `asset_analysis`、系统库 `system_analysis`、网盘 `cloud_assets`），不改原图；API Key 只进钥匙串，模型安装在应用目录。

### 图库与搜索

- 所有来源取消条数截断：图库、网盘、影院、网络影院、电视节目、网络资源命中多少返回多少。
- 图库搜索补齐关键词（`ZKEYWORD`）、端侧标签、OCR、相册、文件夹、人物、场景、地点，不再只搜文件名。
- 系统图库：`tokenKeywordIDs` 把关键词 / AI / OCR 命中换算成资产 UUID 并入 SQL；`nativeKeywordAssetIDs` 先筛小表再按 PK 关联，关键词查询从秒级降到毫秒级。
- 跨库：并发只读检索其它已接入图库，结果按来源分组；点击结果可切 / 连目标库并在原查看器打开。
- 非图库页面（影院 / 电视 / 资源）搜索时，当前图库改走磁盘直连；等待系统分页窗口最多 2.5 秒，避免「0 命中」被会话缓存。
- 搜索会话缓存 4 轮；结果页支持来源 / 类型筛选，返回时保留关键词与筛选。
- 图库导航页的「照片 / 收藏」tab 改为用原查看器打开，不再弹独立预览页。
- 系统图库绑定改为按图库保存（`system_libraries` / `known_libraries` 写入当前库 `settings`）；断开即清理当前库、最近打开与默认库，旧全局记录一次性迁移。
- 图库旁挂布局统一到 `Luma/`：`database` / `originals` / `resources`（derivatives、renders、transcodes、backups、presets、luts、catalog、tv）/ `cloud` / `tv-logos` / `tv-previews` / `source-snapshots`；旧位置继续兼容读取。
- App 支持目录更名为 `Luma`，首次启动迁移旧目录（只认 `ContainerPath.txt` 或 `Models` 标记），设置与模型不丢。

## 1.2.1（2026-11-25）

承接 2.0 基线，版本号按本次发布口径调整回 1.2.1（Build 7），支持 macOS 14 Sonoma 及以上。这一版做「多形态收口」：图库、网络存储、网络影院、网络资源、网络电视收敛到同一套状态组件、任务中心、请求会话、错误恢复、播放 OSD 与入库入口；同时把网络影院补成「多源聚合 + 可换源」，把网络电视补成「可追、可录、可提醒」。

### 网络影院

- 多源同片聚合：同一部片在多个影视源上的条目全部留档，主列表仍按归一化标题只留一条，不再丢源。
- 详情页新增播放源下拉：显示「N 个源」与该源健康状态，点选即切到该源播放；单源时自动隐藏。
- 详情动作区统一：播放 / 继续播放 / 从第 1 集开始 / 预告片 / 稍后看 / 打开原站 / 播放源；稍后看与网络资源共用同一份清单。
- 新增 5 个 AI 工具（影视源、聚合列表、跨源搜索、续看记录、按 ref 播放），AI 工具总数 60。
- 新增内容命令 `playItem` / `watchlist` / `openSourceSite`，详情按钮与 App 菜单统一走 `CommandPolicy`。
- 明确「网络影院」开关只影响网络影视源入口与搜索结果，不影响网盘与本地影片。

### 网络电视

- 赛事多台同播：同一赛事保留全部同播频道，「N 台同播」改为可切台下拉；直播 / 回看 / 提醒对任意同播台生效。
- 录制中心：定时录制、立即录制 30 秒、追剧录与录制列表；到点自动开录，状态覆盖等待 / 录制中 / 已完成 / 失败 / 已取消，录制统一走 `IngestService` 并登记任务。
- 关注球队 / 联赛：按标题分隔符拆词生成候选，赛事行可直接关注；命中关注的行显示徽标，并可为关注赛事批量排提醒。
- 夜航：赛事、黄金时段、热播综艺、人物记录四个板块共享一次节目单扫描；新增「我的关注」与「录制中心」。
- 节目单双 XMLTV 合并（主节目单 + epg.pw 补充），覆盖前 3 天 / 后 3 天；源头部 `url-tvg` / `x-tvg-url` 自动读取，也可手动填写。
- 回看按 `catchup-source` 模板生成，天数源声明优先，未声明按 3 天；回看不并入直播线路。
- 每频道实时抓帧探测（2 路并发），探测报告含分辨率 / 编码 / 码率 / 延迟；线路锁定失效自动回退最佳线路，播放失败顺延备用线路并记录原因。
- 预约、追剧 / 追赛与未来 7 天追剧日历；订阅自动为最近 3 次播出排提醒。

### 六项统一

- 空态 / 骨架 / 失败态：新增 `LumaStateViews`（空态、加载、流光、骨架、失败态），删除各模块自建实现。
- 导航状态：侧边栏源行健康点可点击，弹层复用 `SourceErrorView`，可直接重试或重新登录。
- 任务中心：任务历史收敛为单一 `source_job_history`，影院任务不再单独成线；统一收录云盘扫描、站点健康、影视聚合、TMDB 补全、资源搜索、电视连接检测、节目单更新、频道探测、录制与片头识别。
- 请求配置：新增 `HTTPSessionProfile` 四档（cloud / artwork / probe / stream）与 `HTTPSessionPool`，收编 9 处自建会话；探测画像不带 Cookie。
- 错误恢复：`SourceError` + `RecoveryAction` 覆盖重试 / 重新登录 / 浏览器打开 / 重配来源 / 允许自签证书 / 打开系统设置；新增 Cookie 与 Token 失效识别。
- 播放 OSD：新增 `TVChannelActionCluster`，电视工具栏与播放 OSD 共用频道动作；电视 OSD、点播控制条、影院播放条按钮顺序统一。

### 底座与架构

- `LumaContentCore` 新增 `Commands`（命令策略）、`Ingest`（统一入库）、`IPTV`（M3U / 台名 / 省份）、`MetadataEnricher`（详情补全中心）。
- 网络影院接入统一资料补全：可用线路、TMDB 评分、豆瓣评分（只读缓存）。
- 网络影院快照从 `catalog_kv` 迁入 `catalog_snapshots`（schema v2），与网络资源共用写入、LRU 淘汰与清理。
- 入库收口：`LibraryIngestService.importLocalFile` 成为单文件入库唯一入口，系统库拷贝、剪贴板粘贴、美化输出 4 处旁路全部替换。
- AI 工具 provider 化：`AIToolRegistry` + `AIToolProviders`，中央 switch 不再感知各源细节。
- Cookie / Token 失效统一映射为 `unauthorized`，恢复动作给「重新登录 + 重试」。

### 图库与侧边栏

- 五个模块分区头统一，分区头可点击进入总览；图库 / 系统图库 / 网盘侧边栏共用同一套行与分区组件。
- 新增 `SidebarDropSupport`、`SystemFolderOrganizeSheet`、`SystemToolsSheet`、`ModuleReadoutBar`。
- 图库网格视图控制收进同一胶囊：显示形式、堆叠、排序、筛选、缩略图信息。
- 排序支持拍摄 / 添加时间、文件名、大小、评分与升降序；筛选覆盖收藏、已编辑、关键词、评分、旗标、色标、年份、媒体类型。
- 堆叠支持按时间 / 连拍 / 相似；连拍组双击进查看器整组浏览，其它堆叠原地展开。
- 缩放 ⌘+ / ⌘- / 双指捏合，每个页面独立记忆列数；大图库筛选 / 排序 / 分段下推到 SQLite。
- 视频页补齐统计胶囊、分段视图、年份与时长筛选，以及最近添加 / 值得重看 / 情境影像三条货架。

### 浏览、整理与体检

- 整理工作室：评分、三态旗标、色标、关键词集中筛选与批量修改。
- 智能相簿：满足全部 / 任一，条件覆盖评分、旗标、色标、关键词、年份、媒体类型、收藏、已编辑、人物、地点。
- 图库体检：模糊照片、相似连拍、过大视频、相似去重（保留每组最清晰一张，其余进最近删除）。
- 美化推荐按偏暗 / 偏亮 / 低饱和 / 偏色分组，本机分析并一键生成副本。
- 值得重看收录拍摄超过两年且一年未打开的照片，按人物 / 地点 / 场景 / 年份成主题。
- 批量更改时间、地点、标题、关键词、评分、旗标、色标；相簿 / 文件夹增删改记录撤销点。

### 查看器、编辑器与输出

- HDR 判定优先使用播放窗口所在屏幕，窗口未上屏时任一 EDR 屏即可；HDR 屏 + 自动策略时重编码保留 HDR，杜比视界仍走 libplacebo 映射。
- 4K 且 ≥45fps 的 HEVC、以及系统判定视频轨不可解码的片源直接重编码，避免「有声音黑屏」。
- 网络卷 ffprobe 限制 `-probesize 5M -analyzeduration 1000000`，播放阶段跳过章节读取与二次技术探测，网络超时放宽到 45 秒，NAS 起播不再与探测抢带宽。
- 刷新率匹配延后到首帧后约 800ms，退出播放时统一恢复，减少连播同帧率剧集时的两次黑闪。
- 暂停状态拖动到未生成区间并重建流后，沿用拖动前的暂停意图，不再自动播放。
- 图库视频的 `←` / `→` 改为「上一个 / 下一个项目」，会把照片一起纳入查看器翻页；`⌘←` / `⌘→` 仍只切视频；网络资源与网盘影院剧集模式仍是快退 / 快进。
- 115 网盘播放遇到 403 时，失败页追加「先在 115 网页端完成验证 / 重新保存 Cookie」的指引。

### 图库、性能与索引

- 图库启动改为分片：同步读取第一片 5000 条资产让首屏立刻有内容，剩余资产延迟 1.2 秒后在后台逐片补齐。
- 分片未完成时不再整库落盘，避免把尚未加载的行删除；补齐后补写；切换图库会取消旧分片任务，防止旧库条目混入新库。

### 安全与凭据

- 新增统一凭据保险库：全应用只保留一个钥匙串条目（service `com.baymax.luma.credentials`、account `vault`），网盘密码 / 令牌、影院密钥、字幕账号、AI API Key 全部收进同一个保险库。
