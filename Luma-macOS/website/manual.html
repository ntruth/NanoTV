01产品概览

拾光（Luma）是一个 macOS 原生照片管理应用，使用 SwiftUI + SQLite 构建。界面与交互对齐系统「照片」，并额外提供网络存储（SMB / WebDAV / 阿里云盘 / 百度网盘）与官方「照片」图库接入。

适合谁

照片在本地或 NAS 上、数量从几千到上百万；希望用键盘与文件系统管理照片；不愿意把图库交给云端账号。

不适合谁

依赖 iCloud 跨设备同步、共享图库、视频修剪与屏幕保护输出。这些能力继续使用系统「照片」更合适。

核心原则

图库是一个可移动的文件夹；所有元数据只有一份真源；只读来源绝不直接写入，官方图库的真实写入只经 PhotoKit；端侧智能默认完全在本机完成，云端助手需要显式配置才会启用。

界面结构

左侧为图库范围（拾光 / 系统图库 / 网络存储），中间是网格，右侧或浮层是信息与编辑。查看器覆盖在网格之上。

02开始使用

拾光没有安装器，也没有后台服务。构建产出一份 Luma.app，双击即可运行；所有数据都写在你选择的图库里。

下载现成版本

不想自己编译，可以直接下载发布产物：Luma-2.0.0-macOS.zip（约 90 MB）。解压后把 Luma.app 拖进「应用程序」即可。

产物为 ad-hoc 签名、未做 Apple 公证，首次打开如提示“无法验证开发者”，请右键点击 Luma.app → 「打开」，或执行：

xattr -dr com.apple.quarantine /Applications/Luma.app

全部版本与源码见 GitHub：Releases · 仓库。

系统要求

操作系统macOS 14 Sonoma 或更高
开发工具Xcode 15+ 或 Swift 5.9 工具链
构建方式SwiftPM（Package.swift），无第三方依赖
产物仓库根目录的 Luma.app（可执行文件 Luma）

构建与运行

./build.sh debug     # 日常开发构建
./build.sh           # release 构建
open Luma.app        # 运行

纯逻辑检查（网格布局、缩略图档位、旅行分段）使用断言可执行目标：

swift run LumaCoreChecks

构建脚本会执行 swift build，把可执行文件、Resources/Info.plist 与 Resources/AppIcon.icns 组装成 Luma.app，并做 ad-hoc 签名。

第一次启动

  1. 没有图库时：主界面被建库门禁挡住，只显示引导页。此时不会在固定位置创建任何数据。
  2. 新建图库：选择任意文件夹（可在桌面、外置磁盘或 NAS 挂载点），命名后生成一个 .photoslibrary 包。
  3. 打开已有图库：选择拾光图库，或直接打开官方「照片」图库。
  4. 以后启动：自动打开上次使用的图库；路径记录在 Application Support/PhotosClone/ContainerPath.txt。
  5. 临时切换：按住 Option 启动应用，先弹出「选取图库」面板。

打开、切换与最近图库

操作入口说明
打开图库⌘O / 文件 › 打开图库…打开任意位置的 .photoslibrary，立即成为当前图库
选取图库⌥⌘O / 按住 Option 启动面板列出当前图库、最近打开与 ~/图片 下的所有图库
新建图库⌥⇧⌘N / 文件 › 新建图库…生成新的空图库并切换过去
切换图库设置 › 图库 › 最近使用的图库一键「切换到此图库」；不会搬运内容
切换的含义

打开哪个图库就以哪个图库为准：展示它自己的照片、相簿、设置与系统图库连接。导入、编辑与设置写入它自己的 database/PhotosClone.sqlite，不会把上一个图库的内容搬进来。只有建库引导里的「迁入旧库」才会迁移数据。

应用支持目录

ContainerPath.txt上次打开的图库路径（当前图库的唯一真源）
旧版本地库残留仅在没有图库时用于迁移提示；旧版 SystemThumbs/ 与 SystemLibraryCache/ 不再写入

系统图库缩略图与扫描索引现在写在当前图库包内的 resources/system-thumbs/ 与 resources/system-cache/。应用支持目录位于 ~/Library/Application Support/PhotosClone/，清理缓存不会影响图库本身。

建议的第一次整理

  1. 新建或打开一个图库，设置 › 浏览里选好缩略图尺寸与显示形式。
  2. 把照片拖进窗口，或按 ⌘I 导入；上千张可以分批，导入会并发拷贝并增量落盘。
  3. 重复项目检测（侧边栏「更多项目 › 重复项目」）先合并明显重复。
  4. 「场景 › 分析照片内容…」跑一次端侧分析；需要人物时再运行本地人脸聚类。
  5. 「图库体检」扫一轮，处理模糊、相似连拍与过大视频。所有删除都先进最近删除。

03图库与数据

图库就是一个 .photoslibrary 包。所有图库（自建库与直接打开的官方「照片」图库）的数据都写入包内第一层，因此备份、归档与换机都只是复制一个文件夹。

图库结构

我的图库.photoslibrary/
├── database/PhotosClone.sqlite        # 元数据唯一真源
├── originals/<首字符>/<uuid>.<ext>    # 原图副本
├── resources/derivatives/             # 缩略图
├── resources/renders/                 # 编辑渲染结果
├── resources/transcodes/              # 视频转码缓存
├── resources/backups/                 # 压缩前备份
├── resources/system-thumbs/           # 系统图库缩略图缓存
├── resources/system-cache/            # 系统图库扫描结果缓存
└── cloud/thumbs/                      # 网盘缩略图缓存

数据库里有什么

表内容
assets照片与视频元数据：路径、拍摄时间、相机、地点、尺寸、大小、收藏、隐藏、查看时间等
albums / folders相簿、文件夹与层级关系、自定义封面、相簿内顺序
people本地人物聚类结果与人物关系
settings图库级设置：视图状态、系统图库连接、网盘挂载与收藏、智能助手配置与对话等
asset_analysis端侧场景标签、OCR 文字、二维码 / 条码载荷、归一化特征向量
asset_overlays官方「照片」图库的拾光补充元数据（收藏 / 隐藏 / 关键词 / 查看时间；NULL 表示沿用 Apple 的值）

多图库并存

拾光把「当前图库」与「连接」分开管理：当前图库决定主界面展示的照片、相簿与设置；连接则是同时保留、随时可切过去的其他库。

  • 最近图库最多保留 10 个。可在「文件 › 选取图库…」、按住 Option 启动、设置 › 图库的最近列表里切换。
  • 系统图库连接每个图库最多保存 10 个，记录在当前图库自己的 settings.system_libraries；连接新库不会移除已有连接。
  • 各自独立：照片、相簿、图库级设置、系统图库连接、网盘挂载与智能助手对话都随当前图库切换，不会串数据。
  • 边界：额外连接与网盘只读；当前图库才可写入。图库被移动或删除时，连接会提示找不到并自动移除。
  • 同屏范围：多个库同时保留在侧边栏与列表里，但同一时间只渲染一个「当前图库」的网格；当前版本不提供两个库并排显示。
为什么不做并排双库

每个图库都有自己的 SQLite、缩略图缓存与选择状态。并排渲染会让内存、缓存键与写入目标同时翻倍；当前选择是「多个库同时在线、单库聚焦」，保证大图库下的稳定与写入安全。

官方「照片」图库的写入边界

打开官方图库时，它就是这个 App 的当前图库。照片内容读取 Photos.sqlite，拾光自己的数据写在该库第一层的 database/PhotosClone.sqlite（与 Photos.sqlite 并列）。拾光永远不直接改 Photos.sqlite；需要真实写入时（编辑、删除、相簿增删改、收藏隐藏）只经系统照片接口 PhotoKit，由「照片」自己更新原图与数据库，且需在系统设置里授予照片读写权限。

不要手动搬数据库日志

迁移图库时，禁止直接复制 -wal / -shm：先把旧库三件套复制到临时目录，用 SQLite 执行 wal_checkpoint(TRUNCATE) 合并，再只移动主库文件。把别的库的日志放进当前库目录，会被当成当前库日志回放，覆盖现有数据。

备份与迁移

  • 退出应用后，整包复制 .photoslibrary 即为完整备份；恢复时放回任意位置并用「打开图库」选中它。
  • 外置磁盘未挂载时，拾光不会把「文件不存在」当成删除：元数据保留，缩略图显示占位。
  • 旧版放在 private/com.lijialong.photosclone/ 的数据会在启动或打开图库时自动上移到第一层，幂等且只移动一次。
  • 需要彻底重来：先备份整包，再删除图库包；应用不会在固定位置留下图片。

删除会清理什么

永久删除照片时会一并清理原图、实况照片配对视频、缩略图与快速缩略图、编辑渲染结果、视频转码缓存、压缩备份与网盘缩略图，并在数据库里清掉端侧分析、人脸扫描记录、人物关系、补充元数据与相簿引用；分片目录删空后一并移除。移入「最近删除」只是标记，项目会脱离相簿（相簿封面自动回落），仍可在保留期内恢复。

04浏览

侧边栏决定「看哪个范围」，工具栏决定「怎么看」。所有范围共享同一套缩略图尺寸、排序与筛选，但只有图库层级提供年 / 月时间轴。

侧边栏

侧边栏固定三个分区，每个图库都是独立一套：

拾光

固定项目（默认：个人收藏、人物、地图、位置、视频）、相簿、文件夹、智能相簿、媒体类型与更多项目。右键任意项目可固定或取消固定，拖动固定项可调整顺序；固定列表与顺序随当前图库保存。

系统图库

可保存多个官方「照片」图库连接；同一时间只有一个处于连接/展开状态。连接列表跟着当前图库走，切换图库时整套更换。

网络存储

每个网盘一行；进入后浏览各自目录，能力与本地网格一致（受写入权限限制）。

每个图库按「图库 / 精选集 / 固定 / 媒体类型 / 更多项目 / 场景 / 相簿」排列，媒体类型与场景默认收起。分区标题在悬停时显示「更多」菜单与收起/展开按钮。相簿与文件夹默认收起，只记录你展开过的项目 —— 系统图库可能有上万个相簿。

时间轴：年 / 月 / 所有照片

  • 年：每年一张拼图卡片（最多 4 张照片），点击进入该年的月总览。
  • 月：按月分段，段内按天展示拼图卡片；点击回到所有照片并定位到当天。
  • 所有照片：普通缩略图网格。相簿、文件夹与智能项目也使用普通网格，不显示年 / 月分段。

超过 5,000 张时，年 / 月总览改用 SQL 分区，每个分区最多取 4 张样本，不遍历全库。

四种显示形式

形式适合说明
正方形快速扫图裁剪为等边网格，信息密度最高
完整宽高比看构图按原始比例分组排布，行高统一，每张下方居中显示文件名
瀑布流逛灵感等宽多列、每列高度自适应，竖图横图混排不留空洞；卡片更大、带常驻投影

本地图库、系统图库与网盘共用同一个显示形式设置。缩略图尺寸范围 56–360，可用工具栏滑杆、⌘+ / ⌘- / ⌘0 或触控板捏合调整。

排序、筛选与搜索

  • 排序：拍摄 / 添加日期、标题、文件名、大小、类型、相机、地点、时长。
  • 筛选：全部 / 收藏 / 已编辑 / 照片 / 视频 / 截屏 / 我的 / 未加入相簿。
  • 收藏汇总：进入「个人收藏」后默认先看年份，顶栏可在「全部 / 年 / 类型 / 地点 / 相机 / 人物」之间切换，选择随当前图库保存。全部保持平铺网格；其余每个维度单独一屏，用大卡片汇总——年份（最新年份通栏大卡 + 年份拼图卡）、类型（缩略图拼图 + 占比进度条，照片类型通栏主卡）、地点（城市明信片）、相机（按品牌聚合，相机 / 手机设备插画 + 品牌配色，并列出常见机型）、人物（只统计已命名人物）。点任意卡片只显示该分类的收藏，顶栏「← 维度」返回；系统图库收藏超过 30,000 项时，分类卡片只统计最近一批。
  • 搜索：文件名、标题、相机、地点、关键词、场景标签、图内文字与人物。支持中文自然语言组合，详见「端侧智能」。

选择与信息浮卡

  • 单击选择，⌘ 或 ⇧ 单击多选，拖拽框选，方向键移动。
  • 空格 / 回车 打开所选；⌘A 全选。
  • 悬停可显示可逐项开关的元数据浮层；工具栏「信息」打开浮动信息卡。
  • 信息卡可用方向键切换选中项并就地更新，拖动标题移动、拖动右下角调整大小、双击标题复位。
  • 右键菜单作用于整个选区：选中多张后右键任意已选项目，收藏、隐藏、加入相簿、加关键词、压缩、导出、在访达中显示、删除、恢复、永久删除与从云端删除都会作用于全部所选；右键一张未选中的项目则只针对这一张。菜单文案按整个选区的状态显示。
  • 删除先确认：删除前会弹出确认卡片（扇形缩略图预览 + 数量与照片 / 视频拆分）。不可撤销的操作用红色，并把「取消」作为默认按钮；移入最近删除仍可在保留期内恢复。
  • 网格底部居中显示当前范围的照片与视频总数；有选中项时让位给操作条。

查看器

查看器有两种形态，在设置 › 通用 › 浏览方式中切换，默认「窗口内浏览」：

窗口内浏览

保留侧边栏与顶部工具条：返回、缩放滑杆、信息 / 共享 / 收藏 / 幻灯片 / 编辑 / 更多。照片浮在由自身模糊影像铺成的灯箱底上，竖图两侧不再死黑；顶部悬浮玻璃 HUD 显示日期、小进度环与序号，底部整宽胶片条可随时开关。

全屏沉浸

查看器覆盖整个窗口并隐藏侧边栏，适合专注看图。照片带投影居中显示。

  • 开图渐进加载：先用网格缩略图与 1024px 中等层即时占位，全尺寸解码完成后直接替换，切换照片不做淡入 / 位移。
  • 相邻照片会预取中等层与全尺寸层，连翻不闪白。
  • 查看器内可打开信息面板、编辑、收藏、幻灯片、共享，或用 L 播放实况照片。
  • 画面角标：人像模式照片在左上角显示「人像」；带 GPS 的照片在右上角显示地图图钉，点按直接打开信息面板查看地点名称与地图。
  • 方向键翻页；空格收起查看器；+ / - / 0 或双击缩放。
  • 胶片条可随时开关（设置 › 通用 › 查看器底部缩略图），边看边切换相簿。

动图

  • GIF 在查看器里打开即循环播放；翻到下一张再回来会从头播放。
  • 网盘里的动图会先下载完整文件（限 80MB）再播放，不在浏览时预先下载。
  • 已编辑的照片按静态渲染结果展示；网格仍使用首帧缩略图。

大图库分页

本地图库超过 5,000 张且处于「所有照片」网格时，筛选、排序与计数下推到 SQLite，每页 600 张滚动加载。查看器单步翻页使用 keyset 相邻查询，连翻成本与照片总量无关。

仍需注意的范围

人物、回忆与地图基于内存索引；超百万张时首次进入这些页面会较慢。图库元数据在启动时整体载入内存，分页主要降低筛选、排序与复制的开销。

05组织

相簿、文件夹、智能相簿、人物、地图与体检，共同构成拾光的整理层。所有组织关系都写入当前图库，随图库一起移动。

相簿与文件夹

  • 支持多级文件夹与相簿：新建、重命名、删除、移动、拖拽加入。
  • 点侧边栏文件夹只展示它下一层的子文件夹与相簿（不是照片）；标题旁提供「返回上一级」。
  • 「所有相簿」只展示第一层；进入文件夹后逐层展示下一层。
  • 卡片大小随工具栏缩放（⌘+ / ⌘- / ⌘0）调整。
  • 把照片从网格拖到侧边栏相簿或「所有相簿」卡片即可加入；拖动时显示缩略图与数量徽标，目标高亮。
  • 在相簿网格里把照片拖到另一张照片的左 / 右半侧，可插入其前 / 后，顺序随相簿保存。

相簿显示方式

页头右上角与「显示 › 相簿显示方式」可在网格 / 列表 / 拼贴墙之间切换，系统「照片」图库的相簿层级同样支持。列表与系统「照片」的列表视图一致：方形封面 + 右侧名称与数量，列数随窗口宽度自适应；拼贴墙把 1–4 张照片拼成无边框方块，名称叠加在底部渐变上，方块大小同样跟随工具栏缩放。选择随当前图库保存。

自定义相簿封面

未单独设定封面时，相簿缩略图默认取相簿内的第一张（侧边栏、卡片、列表与拼贴墙一致）。系统「照片」图库则优先沿用其自身的封面设置：先取在「照片」里指定的关键照片，其次 Apple 自动挑选的关键照片，都没有时才回退到相簿第一张。在相簿里右键任意照片或视频，选择「设为相册封面」即可改用它；右键相簿卡片或封面本身可「恢复自动封面」回到首张。封面随相簿持久化；移除该项目时自动回落。

撤销 / 重做

  • 删除（移入最近删除）、从最近删除恢复、收藏 / 隐藏、添加 / 移除关键词、批量更改、相簿与文件夹的新建 / 重命名 / 删除 / 移动、相簿加入 / 移出 / 排序 / 封面、合并重复项目，都支持 ⌘Z 撤销与 ⇧⌘Z 重做。
  • 撤销栈在内存里保留最近 30 步，且只属于当前图库；切换图库即清空。
  • 永久删除、清空最近删除、导入、编辑与压缩不进入撤销栈。编辑器有独立的调整历史，编辑器内的 ⌘Z 只回退调整。

智能相簿

按媒体类型、收藏、已编辑、关键词、相机、镜头、地点、定位、拍摄日期、像素、文件大小、文件名、时长、场景与图内文字自由组合条件。条件之间可选「满足全部」或「满足任一」，编辑时实时预览命中数量。

场景智能相簿

「场景」分区的「更多」菜单可把已识别的场景一键写成智能相簿；之后新分析的照片会自动落入对应相簿。

关键词

按 ⌘K 为所选项目添加关键词；侧边栏「更多项目 › 关键词」可集中管理，也可在搜索框直接输入关键词。

人物

  • 本地图库可用端侧人脸聚类在 Mac 上离线分析，按人脸相似度自动聚合为人物。
  • 支持重命名、查看某人的全部照片；人物页顶部列出「常一起出现」的组合，点开可看两人同框的照片。
  • 照片移入最近删除或被隐藏后不再计入人物；永久删除时同步清理人物关系，没有可见照片的人物自动消失。
  • 系统「照片」图库直接读取官方已有的人物 / 宠物识别结果（包含官方尚未命名的聚类），与系统「照片」的人物列表一致。
  • 聚合筛选：顶栏「全部 / 已命名 / 待命名 / 宠物」与「位置」的省 / 市 / 区县 / 街道是同一套分段控件，选择随当前图库保存。全部视图平铺展示所有人物与宠物，不按命名状态分节；只有点选某一类后才收窄到该分类，筛选为空会给出对应提示。
  • 摘要 / 全部双视图：页头是清晰的大图封面，滚动时自动收缩成紧凑栏。摘要以一句话人物画像开场，配合年度轨迹、光线偏好、常去之地、常一起出现与「色彩气质」（缩略图平均色）等派生卡片，并横向列出每年最值得回看的高光照片；全部则用年份渐变大字做时间节点，按年分段以瀑布流拼贴展示这个人的所有照片。
  • 所有统计都由照片元数据在本机派生，不上传、不落库。

重复项目与相似照片

重复项目按「文件大小 + 像素尺寸」分组，逐组展示；合并时按分辨率、文件大小与收藏挑出「最佳」一张。它与「相似照片」不同：前者处理完全重复，后者按图像特征找同场景 / 同构图。

图库体检

「图库体检」把模糊照片、相似连拍、过大视频与可腾出空间集中成一张清单。清晰度在缩略图上用拉普拉斯方差评估，不解码原图。

  • 体检结果是按范围缓存的派生报告，写入当前图库的 derived_reports（本地 / 系统图库 / 网盘各有独立 key），重开页面直接回填，不必重新扫描。
  • 相似组会保留每组最清晰的一张，其余可一键移入最近删除；不会自动删除。
  • 系统「照片」图库用当前已载入的照片检查；网盘只检查当前目录（最多 500 张），只做只读预览。官方库作为当前图库时，相似备选可以经 PhotoKit 移入「照片」的最近删除。
  • 扫描可随时停止；暂停会保留已检查的部分结果并补齐相似连拍，之后仍可继续查看与处理。

导入项目与最近删除

  • 导入按批次分组，每段显示「导入于 年/月/日 时:分」与该批项目数；批次 ID 随照片写入图库。
  • 最近删除默认保留 30 天，可在设置 › 图库中改为 7 / 30 / 90 / 180 天或永不自动清理。
  • 在「最近删除」中按 ⌘⌫ 会永久删除；其他位置按 ⌘⌫ 只是移入最近删除。

06端侧智能

场景识别与语义向量由本机 SigLIP 2 图文模型完成，物体确认由 YOLO11n 补充，OCR / 人脸 / 人体姿态 / 二维码继续交给 Vision。结果按范围写入当前图库：本地 asset_analysis、系统图库 system_analysis、网盘与派生报告 cloud_assets / derived_reports；不联网、不上传，也不需要账号。

运行分析

  1. 本地图库：侧边栏「场景」分区点「分析照片内容…」，或用「更多」菜单执行整库分析。
  2. 系统「照片」图库：侧边栏「场景 › 识别照片内容…」，在后台持续识别、结果逐张出现，可随时停止。
  3. 网盘：进入目录后点「场景 › 识别内容」，每次最多 120 张，完成后即可按场景与图内文字浏览。
  4. 也可以在信息面板的「智能标签」中就地分析单张照片；需要人物时，进入「人物」页运行本地人脸聚类。
  5. 分析完成后，「场景」「包含文字」与相似照片结果才会出现。调整识别项后可用「重新分析全部照片…」覆盖历史结果。
结果写在哪里

本地写 asset_analysis；系统图库写当前图库的 system_analysis（按图库路径，不写 Photos.sqlite，图库被替换时整批失效）；网盘写 cloud_assets（按挂载 + 路径，远端文件大小变化即失效），断开挂载时一起清理。打开图库不会自动识别，需手动点「识别照片内容…」；视频暂不参与。

识别模型

模型随 App 打包在 Contents/Resources/Models，启动后完全离线推理：

  • SigLIP 2：把缩略图编码成 768 维向量，与 200+ 个中文标准标签的向量做余弦匹配。标签覆盖场景、动物、植物、食物、物品、交通、活动、照片风格（黑白 / 胶片 / 逆光 / 微距 / 航拍 / 长曝光…）、天空天气与文档票据。
  • 去重：标签按分组限额输出（例如动物只留最可信的一个），同一张照片不会同时出现「猫 / 狗 / 动物」这类重复标签；构图上由人脸与人体姿态补充「脸部特写 / 上半身 / 全身」，已有同组标签时不重复添加。
  • YOLO11n：COCO 80 类物体检测，补充猫、狗、鸟、汽车、公交车、披萨、蛋糕、书本等明确主体；模型自带 NMS，只保留置信度与面积都达标的框。
  • 回退：旧系统无法加载新模型时自动回退到 Apple Vision 分类器与特征指纹，已有识别结果仍可继续使用。

历史分析结果来自旧版 Vision 标签，升级后首次点「分析照片内容…」会按版本标记自动重扫，完成前的照片仍按旧标签参与场景与搜索。

场景目录

场景按人物 / 动物 / 宠物 / 畜牧农场 / 鸟类 / 鱼与海洋生物 / 植物花卉 / 自然风景 / 天空与天气 / 食物 / 建筑 / 交通 / 室内 / 文档 / 票据 / 证件 / 证件照 / 二维码条码 / 名胜古迹 / 夜景 / 活动 / 照片风格聚合计数。点任一行查看该场景照片；「更多」菜单可把已识别场景生成智能相簿。

  • 动物与植物：猫、狗、牛、羊、马、猪、鸟、鱼、兔、熊猫、猴子、大象、狮子、老虎、鹿、松鼠、企鹅，以及花、树、草地、叶子、仙人掌、盆栽、樱花、向日葵等由 SigLIP 2 中文标签直接判定。
  • 票据与证件：发票 / 收据 / 门票 / 登机牌、身份证 / 护照 / 驾驶证等由 OCR 关键词判定；发票与身份证再经 LumaCore/DocumentText 规则校验（发票强特征词组合、18 位身份证的出生日期 + GB 11643 校验位），比纯关键词更少误判。
  • 二维码与条码：用 VNDetectBarcodesRequest 检测，并把载荷并入可搜索文字。
  • 证件照：单人脸 + 竖幅 / 方幅 + 居中的人脸启发式；纯色背景半身人像可能误判。
  • 名胜古迹：优先用照片 EXIF 坐标就近匹配内置地标表（国内主要名胜 + 部分海外地标），没有坐标时再用 POI / 城市 / 区县文字匹配；信息面板「智能标签」会显示具体地标名（如「地标 西湖」）。
  • 翻拍类照片会先用 VNDetectDocumentSegmentationRequest 裁出文档区域再 OCR，小字命中率更高。

自然语言搜索

搜索框会解析时间词、类型限定、人物名字与场景词，其余词作为普通关键词匹配文件名、标题、相机与地点。输入整句时（如「海边日落」「吃火锅」「一个女孩」），本地 SigLIP 2 文本编码器会把查询扩展成最接近的中文标准标签再匹配照片；词表里的口语词（如「海边」「烟花」）同时保留直接映射。

相似照片

右键任意照片「查找相似照片」，按 SigLIP 2 语义向量的余弦相似度找出同场景 / 同主体 / 同风格项目。结果在网格顶部显示提示条或胶囊，可一键退出。本地图库用落库向量；系统「照片」图库与网络存储对当前范围最多 80 张缩略图现算向量并写入 system_analysis / cloud_assets，下次直接复用。

智能美化

图库体检页右上角「智能美化」或「照片 › 智能美化…」打开推荐面板。按缩略图把照片分成偏暗 / 偏亮 / 发灰 / 偏色 / 偏软五组，每组显示张数、样本与说明，可「查看」选中这些照片，或「一键美化」批量生成副本（先弹窗确认）；收藏的照片会优先排在前面。

  • 分析只看缩略图，全部在本机完成；推荐结果按范围写入当前图库的 derived_reports，重开面板直接回填。
  • 本地图库生成可还原的美化副本，保留原图与已有编辑。
  • 网盘只读：读取云端大图后按同一套参数渲染，结果作为新照片保存到拾光本地图库，网盘原图不变。
  • 系统「照片」图库默认从官方原图渲染后另存到拾光；当它作为当前图库时，还可以选择「美化原图」，经 PhotoKit 写回，并在「照片」里保留可撤销的调整记录。

存储与隐私

  • 本地：标签、OCR 文字、二维码 / 条码载荷与归一化特征向量写入 asset_analysis；内存索引只保留标签与文字，向量按需读取。
  • 系统图库：识别与特征写入 system_analysis，体检与美化推荐写入 derived_reports，按图库签名失效。
  • 网盘：EXIF、识别、特征与查看记录写入 cloud_assets；人物聚类写入 cloud_people / cloud_person_assets。断开挂载时一起清理。
  • 特征向量不会放进 PhotoItem，也不会进入 JSON；删除照片时同步删除分析记录；分析过程没有任何网络请求。

07智能助手（可选云端）

智能助手是一个独立的可选功能：只有你配置了自己的模型 API Key 后才会联网。它可以问答、检索和整理当前图库；所有写操作都会先弹窗确认。

能做什么

  • 就当前范围提问：照片数量、时间分布、场景构成、某张照片的拍摄信息与端侧标签。
  • 总结与解释：总结选中的一组照片，或结合端侧 OCR 文字解释画面内容。
  • 找照片与视频：用 search_photos / list_videos 搜索当前图库，或按模型给出的关键词与筛选条件应用检索。
  • 整理图库：相簿、文件夹、收藏、隐藏、关键词、标题、原地压缩、自动美化、最近删除与恢复，都可以让助手实际执行。
  • 切换视图：让助手切到收藏 / 视频 / 最近删除 / 某个相簿或文件夹，并同时设置筛选与排序。
  • 操作影院：检索本库影片 / 剧集 / 演员，查看继续观看、观看记录、自定义清单、刮削任务与通知；切换影院分段与筛选，播放影片或剧集下一集；修改收藏 / 想看 / 评分、管理清单、忽略或恢复视频、补全详情或重新刮削、设置跳过片头 / 片尾、移除观看记录。
  • 安全边界：每次修改前弹出确认；不支持永久删除、编辑原图与导入，也不会写入官方「照片」库的 Photos.sqlite。

发送了什么

  • 当前范围摘要：范围名称、项目数、筛选与搜索条件、选中数量。
  • 最多 40 张候选照片的元数据：文件名、拍摄时间、尺寸、收藏 / 编辑状态、关键词、地点、端侧场景标签与 OCR 文字。

  • 更大范围的检索通过模型给出的关键词与筛选条件，回到本地的搜索与分页管线完成。

图片理解（默认关闭）

默认只发文字与元数据。开启「发送压缩缩略图」后，才会把选中照片（没有选中时取当前范围前几张）压成长边约 1024 的 JPEG 发给模型，单次最多 6 张；原始 RAW、视频与云端照片不会发送。模型需要支持视觉输入，例如 glm-4v-flash、qwen-vl-plus 或 gpt-4o-mini。

存储与隐私

  • API Key 只存 macOS 钥匙串（service com.baymax.luma.ai），不写入图库数据库、UserDefaults、日志或对话内容。
  • 模型配置与对话记录保存在当前图库的 settings 中（ai_config / ai_conversation）；切换图库会切换到各自的对话。
  • 请求直接发往你选择的提供商，不经过拾光的任何服务器；关闭助手或清空对话不会影响照片。
  • 写操作由模型调用本地工具完成：先弹窗列出将要创建 / 修改的内容，确认后才通过 LibraryStore 落盘；取消则不会改动图库。
  • 官方「照片」图库作为当前图库时，只允许写拾光补充元数据（收藏 / 隐藏 / 关键词），不允许新建相簿、移动项目或编辑原图，也不能移入最近删除。
模型能力差异

不同提供商与模型的上下文长度、视觉支持与限流策略不同。若报「模型不支持图片输入」，关闭图片理解；若报额度或频率错误，请检查提供商控制台。

08回忆与旅行

拾光会把数量足够的主题自动整理成回忆，也能从定位与时间中识别旅行，把一段行程播成影片。

精选集与回忆卡片

  • 精选集顶部按「按月」「按地点」「收藏」「那年今日」自动生成回忆卡片，只收录数量足够的主题。
  • 「那年今日」按年份（最多最近 3 年）各生成一条，以大横幅置顶。
  • 点击卡片进入回忆影片：均匀取样的照片按 Ken Burns 缓慢缩放平移播放。
  • 支持上一张 / 下一张、暂停与 Esc 退出。

风格与导出

回忆影片提供「经典 / 电影 / 清新」三种风格模板，电影风格带上下黑边。可以导出为 mp4：1280×720、24fps、照片间交叉淡化、无声。

影片是无声的

当前版本不包含配乐，也不支持在导出时剪辑片段。需要带音乐的成片时，请把 mp4 导入其他剪辑工具继续制作。

旅行

  • 按「拍摄时间 + 定位」自动识别出行：时间间隔过大或移动距离过远即切分。
  • 生成「杭州之行」这类旅行卡片，显示日期范围、天数与项目数。
  • 点击卡片打开故事线：首图拼贴 + 按天分组的照片。
  • 可一键「播放回忆」，把整段旅行转成电影风格影片。

09值得重看

「值得重看」不是随机回忆，而是一份按「多久没打开」排序的旧照片清单。它只收录拍摄超过两年、且一年以上没有在拾光里打开过的照片；越久没翻开、拍摄越早越靠前，收藏的照片会略微加权。

今日重看

页面顶部先给一张大图：每天轮换一张最久未翻开的照片，标注「N 年前」、月份与地点，以及上次打开是多久前。可以「翻开这张」进入查看器，也可以「换一张」，或直接跳到这一年的全部旧照片。

按主体拆开

旧照片会按「人物 / 地点 / 场景 / 年份」拆成主体。用顶部胶囊切换只看一类；每张主体卡片显示张数与时间跨度，人物主体带人脸头像。开启「只看未打开」可以过滤掉已经看过的照片。

主体详情与年份胶囊

  • 进入主体后是独立详情页：封面横幅写明最早一张的月份与地点，页头汇总张数、年份跨度、地点数与从未打开的张数。
  • 年份胶囊可一键只看某一年；照片墙支持「最早优先 / 最近优先」，也可以拖拽框选。
  • 页面底部的「时光碎片」瀑布流直接翻看最久未打开的照片，适合没有明确目标时向下逛。

数据从哪里来

  • 主体拆分、排序与摘要文案都在打开页面时由照片元数据在本机派生，不落库、不上传。
  • 「上次打开」来自拾光的查看记录：本地图库写在 assets.viewed_at；网盘写在 cloud_assets.viewed_at；系统「照片」图库使用 Photos.sqlite 里已有的查看时间。
  • 人物主体来自本地人脸聚类或系统 / 网盘已有的人物结果；地点主体与「地图」共用同一套地点聚类。
不是每一张旧照片都会出现

最近两年拍摄的照片、最近一年打开过的照片，以及被隐藏的项目不会进入候选。刚建库时没有查看记录，所有两年前的旧照片都可能被当成「从未打开」。

10地图与足迹

带定位的照片会出现在地图页。地图右上角可切换「网格」，把地点与日期整理成可浏览的行程段。

地图浏览

  • 地图用坐标图钉标注拍摄点，可拖动平移、滚轮缩放。
  • 支持切换卫星底图，选择会被记住；重新进入地图页默认回到地图底图。
  • 左上角「N 个地点 · M 张照片」是当前视野内的统计，随缩放与平移实时更新；点徽标（或右下角「显示全部位置」）回到整库口径。
  • 「网格」与「足迹回放」共用这次缩放的视野：网格只列视野内的照片并重新分段，回放只播视野内的站点；在地图与网格之间切换会保留视野。
  • 信息面板中的地图与地点分级同样来自照片 EXIF 坐标。

地图网格

按「地点 + 连续日期」把带定位的照片切成行程段。段头显示城市、日期范围、张数与「查看地点」入口，下面是跟随缩放的照片卡片墙；换城市或隔天自动分段。

「网格」是一次性浏览方式；重新进入地图页会回到默认地图底图。

足迹回放

把带定位的照片按时间顺序播成一段旅程。先把同一位置（几十米内）的连拍合并成「站」，再逐段运镜：镜头高度随本段距离缩放，街区级的近距离移动也会被拉到满屏可见的尺度，跨城航段自动升到高空并朝向前进方向；光点沿大圆逐帧推进、轨迹随之生长，抵达站点时翻开该站的实拍照片。

  • 卫星三维底图、胶片颗粒、暗角与相机日期水印提供拟物质感。
  • 底部胶片式时间条按照片密度绘制，可拖动定位；支持慢 / 中 / 快三档、空格 暂停与 Esc 关闭。
  • 播完给出里程 / 站点 / 地点 / 天数小结；最多保留 180 个站点（按时间均匀取样）。

地点统计与位置详情

「地点统计」按城市与地点统计照片数量，查看你把时间留在了哪里；点任一行可进入对应照片。点开任意地点则进入独立详情：

  • 页头带封面与坐标网格、显示聚类中心坐标，并随滚动收缩成紧凑栏。
  • 「摘要 / 全部」双视图：摘要提供到访轨迹曲线、四季流转、一天中的时段、镜头里的地标、同行的人、色彩气质与每年高光；全部按月年排成「旅行日志」，年份旁带四季比例条。
  • 照片用瀑布流拼贴并支持拖拽框选；所有统计都由当前地点的照片元数据在本机派生。

11编辑与输出

编辑是非破坏的：原图始终保留，渲染结果另存，编辑配方随图库保存，随时可以重新调整。

编辑器

支持旋转、水平 / 垂直翻转、裁剪与比例、滤镜、曝光、亮度、对比度、饱和度、高光、阴影、色温、色调、锐化、暗角、降噪与自动增强。

  • 保存后生成新的渲染结果，网格与查看器立即使用；cacheKey 含编辑版本，旧缓存自动失效。
  • 可按 ⌥⌘C 复制编辑点，⌥⌘V 粘贴到其他照片；编辑器内也有按钮。
  • 批量更改（⌥⌘B）可一次修改所选项目的标题、拍摄日期与地点。

RAW 与实况照片

  • 支持 DNG、CR2、CR3、NEF、ARW、RAF、ORF、RW2 等 RAW 格式导入。
  • 缩略图、查看器与编辑器统一走 CIRAWFilter（开启高光恢复），失败时回退 ImageIO。
  • 导入时自动把同名 MOV 识别为实况照片的配对视频；查看器内点「实况」或按 L 播放。
  • 导出、复制、删除都会带上配对视频。

导入

  • 入口：拖拽、文件面板（⌘I）、剪贴板粘贴、从系统「照片」导入（⌥⌘I）。
  • 导入始终把原文件拷贝进图库，不支持「引用原位置」。
  • 导入窗口支持按文件夹生成相簿、保留上层结构与进度显示，可取消。
  • 批量导入按 CPU 核数并发（上限 6），过程中增量写入新照片，结束或取消时再同步相簿与文件夹关系。

专业压缩与还原

入口是 ⌘⇧K 或「文件 › 压缩所选」。只作用于本地图库中的照片：视频、系统图库、网盘与最近删除不参与。支持有损与无损两种方式，压缩是原地替换，但可以保留一份逐字节的原图备份。

12系统「照片」图库

官方「照片」图库可以直接作为拾光的当前图库。内容读取 Photos.sqlite，拾光的补充元数据写在 sidecar；需要真实写入时只走系统照片接口（PhotoKit），由「照片」自己更新原图与数据库，拾光不直接改 Photos.sqlite。

作为当前图库打开

  • 主侧边栏直接展示该库自己的结构：图库、精选集、媒体类型、更多项目与相簿；不再显示「拾光 / 系统图库」两个分区。
  • 照片内容读取 Photos.sqlite，包括自定义标题、实况照片与连拍标记。
  • 收藏、隐藏、关键词与查看时间写入该库 database/PhotosClone.sqlite 的 asset_overlays，NULL 表示沿用 Apple 的值。
  • 导入始终写入拾光自己的目录；原图编辑、删除、相簿增删改与收藏隐藏可在授权后经 PhotoKit 写回，关键词与照片标题 PhotoKit 不开放，仍只记录在拾光。

PhotoKit 写回

写回需要系统「照片」的读写权限。执行前拾光会先用样本照片校验「当前打开的就是系统照片库」，不是则拒绝写入。

多个连接（只读浏览）

侧边栏「系统图库」可保存多个图库连接，同一时间只有一个处于连接 / 展开状态。每个连接有独立菜单：在「照片」中打开、重新读取、在访达中显示、断开连接。连接新图库不会移除已有连接；断开前会弹出确认卡片（来源图标 + 图库名称 + 影响说明），只移除侧边栏连接，不删除该图库的任何照片或元数据。

连接列表是 per-library 数据

列表与当前连接保存在当前图库自己的 settings.system_libraries。打开 A 图库只看到 A 的连接，切到 B 图库换回 B 的列表。旧的全局列表只作为一次性迁入来源。

扫描、缓存与载入上限

  • 扫描结果（索引与元数据，不含原图）缓存在当前图库的 resources/system-cache/，缩略图在 resources/system-thumbs/；签名取 Photos.sqlite 的大小 + 修改时间，切换图库不会共用缓存。
  • 扫描是边读边显示的：主库按拍摄日期从新到旧分批到达，视频、截屏等媒体类型不必等整库扫完才出现；顶部进度胶囊显示已读取数量，列表持续增量刷新。十万项以上的大图库在建立浏览索引期间同样逐批出图，索引就绪后自动切换成 SQL 窗口。
  • 缓存命中直接展示；签名变化才后台重扫。缩略图缓存写在当前图库包内，原图直接从官方库读取。
  • 端侧识别与特征写入 system_analysis，体检与美化推荐写入 derived_reports；都只写拾光图库，不写 Photos.sqlite。
  • 超大图库按设置 › 通用 › 系统图库载入 › 载入上限从新到旧截断（可选不限制 / 5 万 / 10 万 / 20 万 / 50 万 / 100 万 / 150 万项，默认不限制），超出时提示真实总数；载入 50 万项以上会占用较多内存，可自行收紧上限。
  • 相簿与文件夹按 ZGENERICALBUM.Z_PK 排序并混排，与官方「照片」一致；默认全部收起。

拷贝到拾光

  • 支持多选照片、单张右键拷贝，或把某个相簿 / 文件夹（含子文件夹）整体拷贝到拾光。
  • 目录递归使用 systemFolderAssetIDs；重复项目按「同名 + 同大小」跳过。
  • 拷贝是唯一写入出口；不会在原库中创建拾光的文件。
iCloud 照片可能未下载到本地

如果官方图库开启了「优化 Mac 存储空间」，部分原图可能仍在 iCloud。拾光读取的是本地文件；需要完整离线副本时，先在系统「照片」中下载原片。

13网络存储

网络存储让 NAS 与云盘直接出现在侧边栏，不必先整库导入。所有凭据只存钥匙串，收藏只记录在本机。

接入入口

侧边栏「网络存储 › ＋」或菜单「文件 › 接入网络存储…」，打开同一个接入向导。选择 SMB、WebDAV、阿里云盘、百度网盘或 AList / OpenList。

SMB 共享

  • 适用于群晖、TrueNAS、Windows 共享等；地址形如 smb://主机/共享名。
  • 通过系统 NetFS 挂载（与 Finder「连接服务器」一致），挂载点由系统决定（/Volumes/<共享名>），拾光复用该挂载点读取。
  • 只读：不支持上传、重命名与删除。支持「在访达中显示」与用系统应用打开。
  • 打开应用时自动重连已保存的 SMB；断开时自动卸载。
  • 向导通过 Bonjour 自动发现局域网设备；共享列表通过系统 smbutil view 获取，密码只经伪终端写入。
  • 新添加的 SMB 默认点开即递归扫描「整个共享」，也可在浏览页切换为「按文件夹」。

WebDAV

  • 可浏览、播放，并支持新建文件夹、重命名、上传与删除。
  • 请求统一走 WebDAVClient，已处理百分号编码、Basic Auth、PROPFIND / MKCOL / PUT / MOVE / DELETE 与 Range。
  • 缩略图优先服务端缩略图；没有时用 Range: bytes=0-262143 读取文件头解析内嵌缩略图，绝不整文件下载。

阿里云盘 / 百度网盘 / AList

  • 阿里云盘与百度网盘使用 OAuth 2.0 桌面端授权，本地回环 127.0.0.1:53682/callback 接收 code，并校验 state。
  • Token 存钥匙串，过期由 CloudService.accessToken(for:) 自动刷新并回写。
  • 两者均为只读：可浏览、播放、幻灯片、打印与导出；不能上传或删除。
  • AList / OpenList 向导填写地址后自动推导 WebDAV 入口。

网盘 EXIF

进入目录后，拾光会自动从文件头部读取前 200 张的拍摄时间、相机 / 镜头、光圈 / 快门 / ISO 与 GPS；WebDAV 与官方网盘用 Range 请求，SMB 直接读挂载文件，不下载整张原图。

  • 侧边栏「媒体类型」下显示读取进度与「继续读取（剩余 N 张）」；可分批读取更多。
  • 结果写回当前列表并落当前图库的 cloud_assets（按挂载 + 路径，远端文件大小变化即失效）。
  • 信息面板的拍摄时间 / 相机 / 位置分区随之生效，并驱动「更多项目」里的地图、位置、人物与值得重看；重开网盘直接回填，不必重新请求。
  • HEIC 等缺少 EXIF 的文件会回退为文件修改时间。

打开网盘后的分类浏览

树结构与系统图库一致：影院（网盘自有）→ 媒体类型 → 更多项目 → 场景 → 相簿，媒体类型与场景默认收起，每个网盘行与各分类都有独立的展开箭头：

  • 媒体类型：视频、全景照片、截屏、录屏（按文件名与像素比例识别）、动图、RAW；数量为 0 的类型不占位。
  • 更多项目：与系统图库同名同序 —— 个人收藏、图库体检、图库整理、值得重看、重复项目、地图、位置、人物、关键词、包含文字、最近查看、最近编辑、最近保存、最近删除、导入项目；点分区标题会像系统图库一样打开卡片总览（数量 + 封面）。图库整理里的评分 / 旗标 / 色标只记在本机；最近编辑 / 最近删除 / 导入项目打开的是同一位置的只读说明页。
  • 场景：点「识别内容」后在本机用 Vision 识别当前列表（每次最多 120 张，可随时停止），结果写入 cloud_assets，重开目录直接回填。
  • 只读派生：地图 / 位置复用拾光的地图与地点卡片墙（缺地名时本机逆地理编码，境外坐标回退到内置城市库按最近城市补国家 / 城市）；人物在本机对网盘缩略图做人脸聚类，结果写入 cloud_people；重复项目按「文件大小 + 像素尺寸」分组，只提示到网盘 App 合并；值得重看用 EXIF 拍摄时间与 cloud_assets.viewed_at 判定；最近查看按本机查看时间倒序；图库体检只检查当前目录；相似照片现算特征并缓存；智能美化把渲染结果保存到拾光本地图库。
  • 断开连接前会先确认：会移除挂载并清理本机缓存的缩略图、收藏与分析记录，网盘上的文件不受影响。

网络与安全

  • 网盘密码、OAuth 凭据与 token 只存 macOS 钥匙串（service com.baymax.photosclone.oauth；旧版条目会自动迁移）。

16数据与隐私

隐私在这个应用里是架构，而不是一句承诺：没有账号、没有遥测与第三方 SDK。端侧智能默认完全离线；可选的智能助手只有在你配置 API Key 后才会调用你选择的模型。

照片默认不上传

端侧场景、OCR 与特征向量由系统 Vision 在本机计算，断网也能完成分析与搜索。本地写 asset_analysis，系统图库写 system_analysis / derived_reports，网盘写 cloud_assets / cloud_people；不写 Photos.sqlite、不写网盘。智能助手默认只发送元数据与端侧标签；图片理解必须显式开启。

数据库在图库里

元数据只有一份真源：图库内的 PhotosClone.sqlite。没有隐藏的云同步或影子数据库。

凭据在钥匙串

SMB / WebDAV 密码、OAuth 应用凭据、token 与智能助手 API Key 只存 macOS 钥匙串，绝不进入日志或设置文件。

写操作有边界

SMB、阿里云盘与百度网盘没有写入路径；官方「照片」图库的真实写入只经 PhotoKit（需授权，由「照片」执行），关键词与标题仍只记在本机。智能助手的修改操作会先弹窗确认，且不支持永久删除或编辑原图。

网络访问清单

  • 端侧分析与本地浏览不需要网络；应用不会在后台发起分析或统计请求。
  • 仅当你主动接入网络存储时，应用才会向对应主机发起连接。
  • WebDAV / SMB / 云盘请求用于列目录、取缩略图、播放、读取文件头 EXIF（Range）与（WebDAV）上传；没有分析或统计请求。
  • 智能助手只在你发送消息时，直接连接你所选提供商的接口；发送内容与图片策略见「07 智能助手」。拾光没有中转服务器。
  • 应用不包含自动更新器，也不会在后台下载内容。

17常见问题

可以在不建库的情况下先看看吗？

不能。没有图库时主界面会被建库门禁挡住，避免在固定位置创建散落数据。先新建一个图库，或打开已有的 .photoslibrary。

为什么照片文件不见了，但记录还在？

外置盘未挂载或文件暂时不可达时，拾光不会把空结果写回数据库。缩略图会显示占位，重新挂载磁盘后即可恢复。请不要在这种情况下执行「清理」类操作。

可以在一个窗口里同时看两个图库吗？

当前只能有一个图库作为「当前图库」。其他官方「照片」图库可以在「系统图库」分区作为只读连接保存，随时展开浏览，但同一时间只有一个连接处于活动状态。

为什么首次分析很慢？

场景、OCR 与特征向量都要逐张读取图片并在本机推理。照片越多耗时越长，但结果只需计算一次；之后搜索与相似检索都走本地数据库。

为什么相似照片不会自动删除？

删除是不可逆的产品决策，必须由你确认。体检与相似检索只给建议；执行删除时会移入最近删除，保留期内仍可恢复。

视频无法播放怎么办？

先确认系统播放器能否打开。系统不支持的容器会由 App 内置的静态 ffmpeg 转封装为 H.264 后播放，无需自行安装；若片源本身损坏或加密，仍可能无法解码。

为什么不能编辑官方「照片」图库里的照片？

可以直接编辑。官方库作为当前图库时，拾光会经 PhotoKit 写回编辑、删除、相簿增删改与收藏隐藏，由「照片」自己更新原图并保留可撤销的调整记录；需要在系统设置里授予照片读写权限。关键词与标题 PhotoKit 不开放，仍只记录在拾光的 sidecar。额外连接的其他官方图库与网盘仍不可写。

「值得重看」为什么照片不多？

它只收拍摄超过两年、且一年以上没有在拾光里打开过的照片，最近两年或最近一年打开过的都不会出现。刚建库时没有查看记录，旧照片会集中出现；看得越多，清单越贴近「真的很久没翻」。

网盘为什么也能看地图、人物和重复项目？

进入目录后拾光会按需读取文件头 EXIF，并用本机 Vision / 人脸聚类在缩略图上做派生。这些结果只写入当前图库的 cloud_assets、cloud_people 与 derived_reports，不修改网盘文件；断开挂载时一起清理。

图库可以放在 NAS 上吗？

可以通过系统挂载的卷使用，但不要把正在使用的图库放在不稳定的网络卷上。断线会导致读写失败，甚至让 SQLite 处于不一致状态。更稳妥的做法是图库放在本地或直连磁盘，NAS 通过「网络存储」浏览。

怎么彻底卸载？

退出应用，删除 Luma.app；如不再需要，可删除图库包与 ~/Library/Application Support/PhotosClone/。应用不写系统级后台服务。

18已知限制

以下限制是当前版本的真实边界，购买或迁移前请先确认。

  • 官方「照片」图库的真实写入只经 PhotoKit（需授权）：编辑、删除、相簿增删改、收藏隐藏可写回，关键词与标题仍只在本机；额外连接的官方图库、SMB 与阿里云盘 / 百度网盘仍为只读。
  • 暂未实现：视频修剪与慢动作变速、iCloud 共享图库、屏幕保护输出。
  • 回忆影片导出为无声 mp4（不含配乐）。
  • 端侧人脸聚类在本地图库与网盘各自独立：本地需要逐张分析，首次运行较慢；网盘只对当前目录做聚类且结果写入当前图库；系统图库只读取官方已有人物结果。
  • 场景、OCR、相似照片、体检与美化推荐在本地、系统图库与网盘都可用，但派生结果按范围分开缓存；视频暂不参与，未分析的照片不会出现在结果里。系统图库只检查当前已载入照片，网盘只检查当前目录（分别最多 500 / 80 张）。
  • 网盘 EXIF 只读取当前目录前 200 张的文件头（可继续读取）；HEIC 等缺少 EXIF 的文件会回退为文件修改时间；网盘上的地图 / 位置 / 人物 / 值得重看 / 重复项目 / 体检 / 相似都基于已读取的目录，只读展示。
  • 撤销栈只保留最近 30 步，且只在当前图库内有效；永久删除、清空最近删除、导入、编辑与压缩不进入撤销栈。
  • 智能助手每次只带当前范围最多 40 张候选照片；更大范围检索通过「应用筛选」回到本地搜索管线。视觉支持、上下文长度与限流取决于所选提供商与模型。
  • 导入始终拷贝原文件，不支持引用原位置。
  • 视频转码由内置静态 ffmpeg 完成；HDR → SDR 色调映射需要带 libzimg 的构建，缺失时退化为普通转码。
  • 多图库：最近图库与系统图库连接会同时保留并可快速切换，但同一时间只渲染一个「当前图库」的网格，不支持两个库并排显示。
  • 压缩：有损（JPEG / HEIC，可调画质与长边）与无损（保持像素与尺寸）两种方式；无损模式对 JPEG 只移除元数据，其它格式转无损 PNG，体积可能不会变小。
  • 「年 / 月」时间轴总览只在图库层级提供；相簿 / 文件夹使用普通网格。
  • 大图库分页覆盖「所有照片」与媒体类型 / 收藏 / 隐藏等本地范围；人物、回忆与地图仍基于内存索引，超百万张时首次进入较慢。
  • 图库元数据仍在启动时整体载入内存；分页主要减少筛选 / 排序 / 复制的开销。
  • HDR 设置对查看器内的静态图片生效；系统级 EDR 行为仍由 macOS 决定。
  • SMB 的「整个共享」扫描在超大目录上首次会较慢，之后刷新会重新读取。
