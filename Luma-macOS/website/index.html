多图库并存

一个窗口，
装下多个图库。

最近图库与官方「照片」连接同时保留在侧边栏，点一下即可切换。每个库拥有独立的照片、相簿、设置、网盘与助手对话。

  • 同时保留：最多 10 个最近图库，每个库再保存最多 10 个系统图库连接。
  • 各自独立：切换库即切换设置、连接与助手对话，不串数据。
  • 边界清晰：额外连接只读浏览，只有当前库可写入。

同一时间渲染一个「当前图库」的网格；多个连接同时在线，但不会把两个库并排显示。

  • 无损模式保持像素与尺寸：JPEG 仅移除 EXIF / XMP / IPTC 与注释，压缩数据原样保留；PNG / HEIC / TIFF 重编码为无损 PNG。

与 macOS「照片」相比

不是替代。
是把缺失的那一层补上。

拾光尊重系统「照片」的位置：iCloud 同步、共享图库与系统级集成继续交给它。拾光负责它做不到的部分 —— 任意图库、超大图库、网络存储、可检查的端侧索引与可带走的内存。

拾光不接管 iCloud。跨设备同步、共享图库、视频修剪与慢动作变速、屏幕保护输出仍请使用系统「照片」；拾光把精力放在本地大图库、可检查的智能索引与多来源浏览上。

隐私，是架构而不是承诺

默认，你的照片
不离开这台 Mac。

没有账号、没有遥测。端侧分析默认离线；可选的智能助手只有在你配置 API Key 后，才会把当前范围摘要（或你显式开启的压缩图）发送给你选择的模型。

0

张照片默认上传

场景、OCR 与特征向量由 Vision 在本机计算，分析结果只写入当前图库：本地 asset_analysis，系统图库 system_analysis 与 derived_reports，网盘 cloud_assets / cloud_people。智能助手默认也不发送图片，只在显式开启图片理解时发送压缩缩略图。

1

个本地数据库

元数据只有一份真源：图库内的 PhotosClone.sqlite。删除记录时同步清理原图、缩略图、渲染与转码缓存。

100%

断网可用

断网状态下依然可以分析场景、识别文字、查找相似与自然语言搜索。云端助手是独立的可选功能，关闭时不发送任何数据。

0

个第三方依赖

SwiftUI + AppKit + Core Image + AVFoundation + Vision + 系统 SQLite。没有 SDK、没有统计组件、没有自动更新器。

网盘密码、OAuth token 与智能助手 API Key 只存放在 macOS 钥匙串；SMB 密码不会进入命令行、环境变量或日志。系统图库与网盘的识别、体检、美化推荐结果都只落在当前图库的缓存表里，断开挂载时一并清理。
