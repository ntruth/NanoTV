# 拾光 Luma 2.1.0 发行说明

- **版本**：`2.1.0`（Build 8）
- **对比基线**：`96391d7`（拾光 Luma 1.2.1）
- **变更规模**：385 个文件随目录更名迁移；另 124 个文件内容修改（+12,498 / −4,547 行），并新增助手、编辑器、模型、文档等文件
- **适用系统**：macOS 14 Sonoma 及以上（Apple Silicon / Intel）
- **发行形态**：`Luma.app` 免安装包 + `Luma-2.1.0-macOS.zip`

---

## 0. 一句话总结

2.1.0 是「AI 与本地智能」版本：把图像理解收口到本机（Vision + SigLIP2 + YOLO），把智能助手升级为可换云端、可接本机运行时的 Agent（73 个工具、三档模式、三种审批），同时修好图库搜索的完整性、补齐专业编辑器，并完成 `Sources/PhotosClone` → `Sources/Luma` 的更名与整套文档重写。

## 1. 汇总

### 1.1 产品角度

- **AI 不再只是问答**：助手能真正检索、建相簿、改评分 / 旗标 / 色标、加关键词、压缩美化、刮削匹配、跨源搜索与播放；写操作有审批，执行有轨迹。
- **模型可以自己选**：云端预置 DeepSeek / Kimi / GLM / 通义千问 / 豆包 / OpenAI，也可接任意 OpenAI 兼容端点；本机可一键探测 Ollama / LM Studio，数据不出本机。
- **图像理解在本机**：OCR、条码、人脸 / 姿态、文档裁切、场景与物体标签、相似向量都在本地完成；SigLIP2 按需下载，未装自动回退 Vision。
- **搜索终于「搜得到」**：图库搜索覆盖关键词、相册、文件夹、人物、场景、地点、端侧标签与 OCR；跨库并发、百万级全量、不做条数截断。
- **编辑器进入专业工作流**：曲线、HSL、分级、五种蒙版、修复克隆、镜头 / 透视 / 拉直、颗粒 / 光晕 / 漏光、海报模板、预设 / LUT / 快照。
- **建库与模块更清楚**：品牌年轮引导、五模块光串、最近图库与断开连接；网络影院源不再混进网络资源。
- **电视更能管**：按国家分组、多地址 / 文件 / 分享包导入、跨源节目搜索、2×2 多画面。
- **影院更好逛**：单源聚焦浏览、海报缩放、刚上架 / 更新中 / 已完结角标、合并同名计数。

### 1.2 技术角度

- **目录与产物统一**：`Sources/PhotosClone` → `Sources/Luma`，target / product / executable 统一为 `Luma`；`build.sh` 新增 `preview` 快速预览分支。
- **AI 工具 provider 化继续推进**：`AIToolRegistry` 按模块注册影院 / 资源 / 网络影院 / 电视工具，中央 switch 不再感知各源细节。
- **搜索下推与跨库**：`SystemQuery.tokenKeywordIDs`、`SystemIndex.nativeKeywordAssetIDs`、`LibrarySearchCrossLibrary`、`waitForSystemWindow` 组成完整的图库搜索链路。
- **图库生命周期收口**：App Support 目录更名并迁移；旁挂数据统一 `Luma/`；系统图库绑定按图库保存并可断开清理。
- **模型管线**：清单多源、断点续传、SHA-256、`.mlpackage` 编译、原子替换与回滚，全部在应用目录完成。
- **编辑器拆分**：曲线、HSL、蒙版、修复、镜头、创意、海报、预设等模块独立，避免单个文件继续膨胀。
- **文档体系重写**：README 产品化，新增产品设计 / UI 设计 / 代码开发三份文档与竞品矩阵。

### 1.3 功能角度

- AI：73 个工具、三档模式、三种审批、执行轨迹、检索建议、对话持久化、模型安装与本地运行时。
- 图库：搜索完整性、跨库打开、系统图库绑定、编辑器专业模块、建库引导、模块光串。
- 影院：单源聚焦浏览、新鲜度角标、海报缩放、同名合并计数。
- 网络资源：FongMi / 分享包 / 地址导入，爱看片片与爱壹帆适配器升级。
- 网络电视：国家分组、多地址与分享包导入、跨源节目搜索、多画面。
- 播放：按住快进 / 快退逐级加速。

## 3. AI 与本地推理

### 3.1 智能助手

- **工具总数 73**：基础 40（照片 / 相簿 / 文件夹 / 影院匹配）+ 本地影院 13 + 网络资源 9 + 网络影院 5 + 网络电视 6。
- **新增图库工具 7 个**：`get_photo_info`、`list_keywords`、`list_people`、`library_overview`、`set_rating`、`set_flag`、`set_color_label`。
- **新增电视工具 6 个**：`list_tv_sources`、`list_tv_channels`、`get_tv_guide`、`play_tv_channel`、`favorite_tv_channel`、`navigate_tv`。
- **三档模式**：
  - 快速：24 张候选、历史 ≤3 轮、工具 ≤12 轮。
  - 标准：40 张候选、历史 6 轮、工具 80 轮。
  - 深度：64 张候选、历史 ≥10 轮、工具 ≥150 轮（上限 300）。
- **审批策略**：每次确认 / 仅高风险 / 自动应用；35 个写工具；8 类高风险加清单删除动作；一次回复里的多个动作合并为一个确认框，取消会以工具错误回传模型。
- **执行轨迹**：连续工具回执合并，超过 4 步折叠；失败结果回传模型继续推理；统一任务条可取消。
- **面板重做**：能力分区与示例、Markdown 渲染、耗时 / 工具轮数、重新生成、复制、面板缩放记忆、思考态。
- **防「假完成」**：有操作意图但模型没调用工具时提醒一次；仍未执行则明确报错，不把方案当结果。
- **检索建议**：回答可附带关键词 / 筛选 / 照片 ID，一键套用到当前网格。

### 3.2 模型接入

- 云端预置：DeepSeek、Kimi、GLM（智谱）、通义千问、豆包（火山方舟）、OpenAI、自定义 OpenAI 兼容端点。
- 本机运行时：自动探测 Ollama `127.0.0.1:11434` 与 LM Studio `127.0.0.1:1234`，读取 `/models` 列表；不需要 API Key。
- 连接测试：设置页可直接发一条测试消息，返回摘要或错误。
- 视觉输入：默认关闭，只发元数据 + 端侧标签 / OCR；开启后发送长边 1024、质量 0.72 的 JPEG，默认最多 4 张（可调到 6）。
- 隐私：API Key 只存钥匙串；对话随图库保存，只存文字与照片 ID，不存图片。

### 3.3 本地图像理解

- **Vision**：精确 OCR（简中 / 英文、语言纠正）、全部条码 / 二维码、人脸、人体姿态、文档分割与外接矩形裁切。
- **SigLIP2**：零样本中文标签、768 维图像向量；文本塔用于自然语言查询扩展。
- **YOLO11n**：COCO 80 类目标检测，置信度阈值 0.4，补充主体标签。
- **规则补强**：发票 / 身份证文字校验；构图标签「脸部特写 / 上半身 / 全身」；单人竖幅 / 方幅证件照判定。
- **相似与体检**：图像向量用于相似照片；Laplacian 方差判模糊（阈值 55）。
- **结果落库**：本地 `asset_analysis`、系统库 `system_analysis`、网盘 `cloud_assets`；不改原图。

### 3.4 本地模型管理

- **SigLIP2**：约 350MB（图像 92MB + 文本 259MB），macOS 15+；hf-mirror / HuggingFace 双源；词表随包约 9MB。
- **安装流程**：清单 → 断点续传 → SHA-256 → ditto 解压 → `.mlpackage` 编译 Core ML → 必备文件校验 → `.ready` 标记 → 原子替换；失败回滚旧版本。
- **其他能力**：离线目录导入、启停、卸载；模型放应用目录，不随图库迁移；未安装或旧系统回退 Vision。
- **本地语言模型**：GGUF 组件位已留，运行时不内置；当前用 Ollama / LM Studio。

## 4. 图库与搜索

- **取消条数截断**：图库、网盘、影院、网络影院、电视节目、网络资源全部返回完整命中。
- **图库命中字段**：文件名 / 原始文件名 / 标题 / 相机 / 镜头 / 地名 / 关键词（`ZKEYWORD`）/ 场景 / OCR / 人物 / 相册 / 文件夹。
- **系统图库关键词**：`tokenKeywordIDs` 把关键词 / AI / OCR 命中换算成资产 UUID，并入每个 token 的 OR 条件。
- **关键词查询提速**：`nativeKeywordAssetIDs` 先筛 `ZKEYWORD` 小表，再按 PK 关联资产；整表 join 的秒级查询降到毫秒级。
- **跨库搜索**：并发只读检索其它已接入图库，结果按来源分组；点击可切 / 连目标库并在原查看器打开。
- **非图库页搜索**：浏览影院 / 电视 / 资源时，当前图库改走磁盘直连；等待系统分页窗口最多 2.5 秒，避免「0 命中」被缓存。
- **会话缓存**：按「关键词 + 来源集合」保留最近 4 轮。
- **图库导航页**：照片 / 收藏 tab 改为原查看器打开，不再弹独立预览。
- **系统图库绑定**：改为写入当前图库 `settings`（`system_libraries` / `known_libraries`）；断开即清理当前库、最近打开与默认库，旧全局记录一次性迁移。
- **旁挂布局**：统一 `Luma/`（database / originals / resources / cloud / tv-logos / tv-previews / source-snapshots）；旧位置兼容读取。
- **App Support**：目录更名为 `Luma`，首次启动迁移旧目录（只认 `ContainerPath.txt` 或 `Models` 标记）。

## 7. 影院与网络影院

- **单源聚焦浏览**：选中影视源后进入它的首页 / 分类 / 搜索 / 下滑翻页；返回聚合页恢复原列表与滚动位置。
- **单源控制台**：首页、全部、分类、搜索、刷新集中在一条控制台。
- **海报缩放**：按行调整海报数量，带无障碍标签。
- **空态**：没有影视源时给出「接入影视源…」，并说明支持 FongMi、苹果 CMS、FoFo / 爱看片片 / 爱壹帆。
- **新鲜度**：刚上架 / 更新中 / 已完结；显示「本次刷新新增 N 条」与「已合并 N 部同名」。
- **多源**：同名条目继续按标题归并，卡片标 N 源，详情可换源；失败回退与重试沿用 1.2.1。

## 9. 网络电视

- **国家分组 / 筛选**：`TVCountries` 覆盖中国大陆、香港、澳门、台湾、日本、韩国、欧美等。

- **多画面**：2×2 最多 4 路 HLS，声音跟随一个频道。
- **沿用**：直播 / 回看 / 线路切换 / 开播提醒 / 录制中心 / EPG 时间轴与时间环。

## 10. 视频播放

- **按住加速**：按住快进 / 快退按 1 → 2 → 3 → 4 → 6 → 8× 逐级放大步长。
- **重复节奏**：首次 0.30 秒，之后每拍减 20ms，降到 0.14 秒后匀速。
- **边界**：单步上限 600 秒；换向或停手 1.2 秒复位到 1×；网络未生成区间会重建流。
- **文档化**：原生直读 / 无损转封装 / 重编码 / 直播四条决策链与实测状态写入 `docs/`。
- **沿用 1.2.1**：字幕、音轨、HDR、缓冲档位、缓存、片头片尾跳过、画中画、截帧。

## 13. 已知限制

- 百万级图库的文件名 / 关键词仍是 `LIKE` 全表扫描，FTS 未做。
- HDR10+ 动态元数据、多码率 ABR、Atmos 对象层、ffmpeg 硬解、蓝光菜单与加密盘未做。
- 内置 GGUF 本地语言模型未接入；无 Skill 市场 / MCP / 多 Agent；模型回复非流式。
- 电视录制依赖 App 运行与源站可拉流；回看依赖源 catchup。
- SigLIP2 需 macOS 15+；未安装时回退 Vision。
- 系统图库写入受权限与 PhotoKit 能力限制。

## 15. 升级建议

- 首次启动会把旧 App Support 目录迁到 `Luma`，迁移期间不要同时打开旧版本。
- 图库旁挂数据会自动兼容旧位置；如果图库在外置盘，先挂载再打开。
- 使用 SigLIP2 需要 macOS 15+；macOS 14 上继续使用 Vision，不影响浏览与搜索。
- 使用本机大模型时，先在 Ollama / LM Studio 里下载模型，再到设置 › 助手 › 本地运行时点「检测」。
- 电视源升级后会清理历史内置测试源，需要重新导入自己的 M3U / 分享包。
